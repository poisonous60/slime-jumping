# SlimeJumping — 핵심 메커닉 설계 v3

## 컨셉

**점성 슬라임** — 모든 표면에 달라붙는 것이 자연 상태. 이동은 크롤링과 차징 발사로 수행.  
슬라임의 물성(처짐, 안정도, 무게중심)이 발사 성능에 직접 영향을 주지만, **조작 자체는 가볍고 즉각적**.  
WASD + Space 키로 조작. 모든 시간 단위는 **초(seconds)** 기준.

**장르 지향**: 점프킹, Egging On, 셀레스트, 구구피자 계열의 정밀 플랫포머.  
바운스나 점착은 비주얼과 발사 성능에 영향을 줄 뿐, 조작 반응성을 저해하지 않는다.

---

## 1. 슬라임 물리 시스템

### 노드 구조

중심 1개 + 주변 6개, 총 **7개 노드**가 스프링으로 연결된 링 구조.

```
      ●
     / \
   ●  ●  ●    중심(C) + 주변 6개(N)
   |  C  |     C↔N 스프링 + N↔N 스프링
   ●  ●  ●
     \ /
      ●
```

- **C↔N 스프링**: 중심과 주변 노드 연결. 전체 형태 유지.
- **N↔N 스프링**: 이웃 주변 노드끼리 연결. 외곽 형태 유지.
- 스프링 파라미터(강성, 감쇠)로 슬라임의 탱탱함/물렁함 조절.

### 중심 노드 — 키네마틱 분리

**중심 노드는 물리 적분(Integrate)을 타지 않는다.** SlimeController가 직접 Position과 Velocity를 제어한다.

- 이동(크롤링), 차징 발사, 에어 컨트롤 등 모든 게임플레이 로직은 중심 노드 하나에 대해 **단일 원형 콜라이더 기반**으로 처리.
- 점프킹/셀레스트와 동일한 반응성 확보.

**주변 6개 노드**는 기존대로 스프링 물리로 중심을 따라간다.

- 표면에 닿으면 점착, 중력으로 처짐, 스프링 복원 — 전부 유지.
- **스프링 힘의 역전파 차단**: C↔N 스프링은 중심 → 주변 방향으로만 당긴다. 주변 → 중심 방향의 힘은 무시.
- 바닥에 노드가 몇 개 붙어있든 A/D 입력은 중심을 즉각 움직이고, 주변 노드가 끌려오며 자연스럽게 점착이 해제되거나 늘어나는 비주얼 연출.

**레이어 분리 원칙**: 게임플레이는 원 하나, 비주얼과 안정도 산출은 소프트바디.

## 2. 표면 부착 & 앵커 드리프트

### 점착 기본

- 주변 노드가 표면에 닿으면 **AdhesionPoint** 생성 (앵커 위치 + 표면 법선).
- 스프링이 노드를 앵커로 당김.

### 앵커 드리프트 (3단계 모델)

점착은 "붙거나 떨어지거나"가 아닌, **흘러내리는 중간 단계**를 갖는다.

| 스프링 힘 구간 | 앵커 상태 |
|---------------|-----------|
| `force < staticThreshold` | **정지** — 앵커 고정. 안정적으로 붙어있는 상태. |
| `staticThreshold ≤ force < breakThreshold` | **드리프트** — 앵커가 표면을 따라 힘 방향으로 미끄러짐. |
| `force ≥ breakThreshold` | **해제** — 점착 즉시 끊어짐. |

```
if (springForce > staticThreshold && springForce < breakThreshold)
    anchor += forceDirection.tangentToSurface * driftSpeed * dt;

if (anchor가 표면 밖으로 나감)
    adhesion 해제;
```

**표면 밖 판정**: 앵커 위치에서 표면 방향으로 짧은 레이캐스트 → 콜라이더에 안 맞으면 해제.

### 안정도

```
안정도 = 부착된 주변 노드 수 / 전체 주변 노드 수 (6)
```

안정도가 발사력에 영향. 이동 조작과 발사 방향에는 영향 없음.

### 무게중심 오프셋

```
CoM 오프셋 = 전체 노드 무게중심 - 부착 노드 평균 위치
```

비주얼 연출과 안정도 하락 연출에 사용. **발사 방향에는 영향 없음** — 방향은 순수하게 플레이어 입력으로만 결정.

## 3. 표면별 상호작용

### 바닥

- 착지 시 다수의 노드가 부착. 안정도 높음.
- 시간이 지나도 안정적. 여유롭게 조준 가능.

### 벽

- 벽쪽 노드가 부착. 부착되지 않은 노드가 중력으로 처짐.
- 앵커 드리프트로 노드가 아래로 흘러내림 → 가장자리 앵커가 표면 밖으로 나가며 해제 → 안정도 하락 → 연쇄 해제 → 떨어짐.
- **중심 노드 드리프트**: 컨트롤러가 안정도에 연동하여 중심 노드를 중력 방향으로 밀어냄.

```
float drift = baseDriftSpeed * (1 - stability * stabilityHoldFactor);
centerNode.Position += gravity.normalized * drift * dt;
```

- 안정도 높으면 거의 안 흘러내림, 안정도 떨어지면 가속.
- **빨리 쏘면 높은 위치에서 강하게 발사. 늦으면 낮아지고 약해짐.** 자연스러운 시간 압박.

### 천장

- 천장쪽 노드가 부착, 나머지 전부 아래로 처짐.
- 벽보다 불안정. 부착 유지 시간이 짧음.
- 천장 발사는 고급 테크닉.

### 좁은 플랫폼

- 부착 면적이 작아 소수 노드만 부착. 안정도 기본 낮음.
- A/D로 치우치면 반대편 앵커가 가장자리로 드리프트 → 표면 밖으로 나가며 해제 → 떨어짐.
- 정밀한 위치 조정이 중요.

### 원형/곡면 플랫폼

- 곡면을 따라 노드 부착. 무게중심이 부착점 바로 아래이면 균형 유지.
- A/D 이동 시 무게중심이 쏠리면서 기울어짐 → 떨어짐 위험.

## 4. 이동

### 표면 크롤링

- 스페이스를 누르지 않은 상태에서 **WASD**로 천천히 기어다님.
- 바닥: A/D 좌우. 벽: W/S 위아래. 천장: A/D 좌우.
- 이동 속도는 느림 — 위치 미세 조정용이지 주 이동 수단이 아님.
- 이동 시 주변 노드가 순차적으로 부착/해제되면서 "흘러가는" 비주얼.
- **스페이스 홀드 중에는 A/D가 조준 회전으로 전환.** 크롤링 중단. W/S는 차징 중 미사용.

### 주 이동 수단: 차징 발사

- 표면에서 표면으로의 이동은 전부 차징 발사로 수행.

## 5. 차징 & 발사

### 원리

슬라임이 내부적으로 압축된 뒤, 압축 반대 방향으로 튕겨나가는 슬링샷 방식.  
**차징은 슬라임 자체의 내부 메커니즘**이며, 접촉 표면과는 독립적으로 동작한다.  
**모든 표면에서 차징 가능** — 바닥, 벽, 천장 어디서든.

### 압축-발사 모델

차징 시 슬라임이 특정 방향으로 몸을 압축하고, 발사 시 **압축 반대 방향**으로 날아간다.

- A/S 입력으로 슬라임이 왼쪽 아래로 압축 → 발사는 오른쪽 위.
- D 입력으로 슬라임이 오른쪽으로 압축 → 발사는 왼쪽.
- 비주얼: 차징 중 슬라임이 압축 방향으로 찌그러지고, 발사 시 반대로 늘어나면서 튀어나감.

### 초기 방향 & 조준

- **스페이스 홀드 = 차징 시작.** 초기 압축 방향은 **접촉 표면의 법선 안쪽** (표면을 향해 눌림). 발사 기본 방향은 법선 바깥쪽.
  - 바닥: 기본 압축 아래, 기본 발사 위.
  - 오른쪽 벽: 기본 압축 오른쪽, 기본 발사 왼쪽.
  - 30° 경사면: 기본 발사 경사 수직 방향.
- **A/D = 조준 회전.** 차징 중 A/D로 압축 방향을 초기 법선 기준으로 회전. 아날로그 각도 조절.
- **W/S는 차징 중 미사용.**

```
// 차징 진입 시
initialAngle = surfaceNormal.angle;  // 법선 방향 (발사 기본 방향)
currentAngle = 0;                     // 법선 기준 오프셋

// 매 프레임
currentAngle += input.x * rotationSpeed * dt;  // A/D 회전

// 압축 방향 = 발사 반대
launchDirection  = angleToVector(initialAngle + currentAngle);
compressDirection = -launchDirection;
```

표면 종류에 따라 입력을 다르게 매핑할 필요 없음. "법선에서 시작, A/D로 돌림"이라는 하나의 규칙이 바닥/벽/천장/경사면에 자동으로 맞아떨어짐.

### 차징 파워와 조준 관성

차징량이 높을수록 조준 회전이 뻑뻑해진다. 에너지가 많이 실린 상태에서는 관성이 커서 방향 전환이 어려움.

```
rotationSpeed = baseRotationSpeed * (1 - chargeRatio * resistFactor);
```

- **약하게 차징**: 회전 자유. 조준 정밀.
- **강하게 차징**: 회전 경직. 방향을 미리 잡아놔야 함.

### 큐빅 커브와 자연스러운 조준-파워 페이즈 분리

파워 커브가 **큐빅(t³)**이므로, 초반에는 chargeRatio가 거의 올라가지 않는다. 이 구간이 자연스러운 조준 페이즈가 된다.

풀차지 시간 **1초** 기준 (튜닝 출발점):

| 구간 | chargeRatio | 조준 상태 | 역할 |
|------|-------------|-----------|------|
| 0.0 ~ 0.4초 | 0 ~ 0.064 | 회전 거의 자유 | **조준 페이즈** — 방향 잡기 |
| 0.4 ~ 0.7초 | 0.064 ~ 0.34 | 슬슬 뻑뻑해짐 | **미세 보정** — 방향 확정 |
| 0.7 ~ 1.0초 | 0.34 ~ 1.0 | 급격히 잠김 | **파워 페이즈** — 파워만 충전 |

별도의 조준 타이머 없이, 큐빅 커브 하나가 조준 여유 / 파워 곡선 / 회전 경직을 동시에 제어.

### 발사 트리거 (2가지)

1. **스페이스 릴리즈** — 원하는 타이밍에 수동 발사.
2. **풀차지 자동 발사** — 차지 게이지가 최대에 도달하면 즉시 자동 발사.

풀차지 자동 발사는 벽/천장에서 흘러내리는 시간 압박과 결합하여 이중 압박을 형성:
- 안정도 하락 압박 (너무 늦으면 약해짐)
- 차지 게이지 압박 (너무 오래 들고 있으면 의도치 않은 타이밍에 발사)

### 차징 규칙

- 홀드 시간에 비례하여 파워 증가. **큐빅 커브 (t³).**
- **풀차지 시간: 1초** (튜닝 출발점).
- **차징 캔슬 불가.** 스페이스를 누르면 무조건 발사까지 진행. 커밋.
- **발사 후 입력 무시 윈도우: 0.05초.** 잔여 키 입력 무효화.

### 안정도 영향

```
실제 발사력 = 기본 발사력 × 차징 커브(t) × 안정도
```

- 안정도 높음 → 풀파워.
- 안정도 낮음 → 약한 파워.
- **발사 방향은 순수하게 플레이어 입력으로만 결정.** CoM 오프셋에 의한 방향 편향 없음. 정밀 플랫포머에서 방향 예측 가능성 확보.

## 6. 벽 충돌 — 바운스 없음, 에너지 전환

### 핵심 원칙

**벽에 부딪히면 튕겨나오지 않는다.** 무조건 벽에 붙는다.  
바운스 메커니즘은 전면 삭제.

### 두 가지 충돌 모드

| 충돌 시 스페이스 상태 | 결과 |
|----------------------|------|
| **안 누르고 있었음** | 철퍼덕 붙음. 운동에너지 전부 소멸. 이후 일반 차징으로 발사. |
| **누르고 있었음** | 충돌 속력이 차징 에너지로 전환. 이미 차지가 차있는 상태로 벽에 붙음. |

### 운동에너지 전환 규칙

```
storedPower = min(impactSpeed * conversionRate, maxChargePower)
```

- 전환된 에너지는 차지 게이지의 **초기값**으로 세팅. 일반 차징의 풀파워가 상한.
- 빠르게 박으면 거의 풀차지 상태 → 조준 회전이 뻑뻑하고 풀차지 자동 발사까지 여유 없음.
- 느리게 닿으면 반차지 정도 → 조준 자유롭고 여유 있지만 파워 약함.
- 벽에 붙은 후 스페이스를 계속 들고 있으면 게이지가 계속 차오름. 놓으면 수동 발사, 풀차지되면 자동 발사.

### 방향 입력

- 운동에너지 전환 시에도 **벽에 붙은 순간부터** A/D로 조준 회전 가능.
- 단, 전환된 차지량이 높을수록 회전이 뻑뻑함 — 빠르게 박으면 방향 전환 여유가 적음.

### 설계 의도

**사전 커밋 원칙의 일관성**: 차징도 캔슬 불가, 벽 충돌도 "부딪히기 전에 스페이스를 누를지 말지 미리 결정해야 한다." 예측하고 커밋한 플레이어가 보상받는 구조.

## 7. 공중 제어

- **A/D**: 수평 방향만 약하게 보정. 수직 속도는 건드리지 않음.
- 에어 컨트롤은 **방향만 틀고 속력은 바꾸지 않음.** 같은 방향 가속 불가.
- 완전한 U턴 불가능, 완만한 곡선 보정만 가능.

### 대칭 중력

- **상승/하강 동일한 중력 적용.** 비대칭 중력(fallMultiplier) 삭제.
- 대칭 포물선으로 궤적 예측 가능성 극대화.
- 체공감이 과하면 기본 gravity scale을 올려서 조절 (포물선이 납작해지면서 상승도 하강도 빨라짐).
- 차징-커밋 구조에서는 "이만큼 차징하면 이 포물선"을 학습하는 게 핵심. 대칭이 학습에 유리.

### 공중 슬라임 형태

- 주변 노드들이 자유롭게 움직이며 슬라임이 늘어지거나 회전.
- 표면에 닿는 순간 접촉 노드가 부착되면서 착지 형태 결정.
- 착지 각도에 따라 부착 노드 수와 위치가 달라짐 → 착지 자세가 안정도(= 다음 발사 파워)에 영향.

| 항목 | 수치 |

## 9. 입력 요약

### 표면 (바닥/벽/천장 공통)

| 입력 | 동작 |
|------|------|
| WASD | 표면 위 크롤링 |
| Space 홀드 | 차징 시작 (초기 방향 = 표면 법선) |
| Space + A/D | 조준 회전 (차징량 많을수록 뻑뻑해짐) |
| Space 릴리즈 | 발사 (수동) |
| Space 홀드 → 풀차지 | 발사 (자동) |

### 공중

| 입력 | 동작 |
|------|------|
| A / D | 수평 궤도 보정 (속력 불변, 방향만) |
| Space 홀드 | 벽 충돌 시 운동에너지 전환 준비 |

### 벽 충돌

| 충돌 시 상태 | 결과 |
|-------------|------|
| Space 안 누름 | 붙음. 에너지 소멸. 일반 차징 시작 가능. |
| Space 누르고 있음 | 붙음. 충돌 속력 → 차지 에너지 전환. |

## 10. 설계 원칙 요약

1. **게임플레이는 원 하나, 비주얼은 소프트바디**: 중심 노드 키네마틱으로 즉각 반응성 확보. 주변 노드 물리로 슬라임다운 비주얼과 안정도 산출.
2. **점성 슬라임**: 모든 표면에 달라붙는다. 바운스 없음.
3. **물성이 곧 메커닉**: 처짐, 안정도가 발사력에 직접 영향. 단, 이동 조작과 발사 방향에는 영향 없음.
4. **입력 단순**: WASD + Space. 5개 키로 모든 조작.
5. **시간 압박은 물리에서 나온다**: 벽/천장에서 앵커 드리프트 + 중심 드리프트로 안정도 하락. 풀차지 자동 발사로 이중 압박.
6. **차징은 커밋**: 캔슬 불가. 방향은 A/D 회전으로 발사 순간까지 조절 가능.
7. **파워-조준 트레이드오프**: 강하게 쏘면 조준이 뻑뻑해지고, 약하게 쏘면 조준이 자유롭다. 큐빅 커브가 자연스러운 조준→파워 페이즈 전환을 만든다.
8. **사전 커밋 보상**: 벽 충돌 전 스페이스를 미리 누른 플레이어가 에너지 전환 보상을 받음. 높은 전환량 = 조준 여유 감소.
9. **대칭 중력**: 포물선 예측 가능성. 차징-커밋 구조에 최적.
10. **시스템 분리**: 중력 → 수직, 에어 컨트롤 → 수평. 이동 반응성 / 벽 드리프트 속도 / 비주얼 처짐을 독립 튜닝.

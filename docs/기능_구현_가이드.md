# 기능 구현 가이드

각 기능을 구현할 때 어떤 카테고리에 속하는지, 어떤 인터페이스를 구현하고, 어떤 기존 코드를 참고해야 하는지 정리.

---

## 카테고리 요약

| 카테고리 | 인터페이스/베이스 | SlimeController 접점 | 대표 구현체 |
|----------|------------------|---------------------|------------|
| 위험 | `IHazardSource` | `ApplyHazardEffect()` → Stunned | `SpikeHazard.cs` |
| 플랫폼 효과 | `IPlatformEffect` | `OnSlimeAttach/Stay/Detach`, `ForceAirborneWithVelocity()`, `AddExternalVelocity()` | `JumpPad.cs`, `ConveyorBelt.cs` |
| 환경 존 | `EnvironmentalZone` (abstract) | `AddExternalVelocity()`, `MultiplyVelocity()`, `ClampFallSpeed()`, `PushBlockAttach()` | `WaterZone.cs` |
| 인터랙터블 | `IInteractable` | 없음 (InteractionDetector가 중계) | 미구현, 새로 작성 |
| 오버라이드 | `IExternalController` | `SetOverride()` / `ReleaseOverride()` | 미구현, 새로 작성 |
| 자체 시뮬 | 없음 | 없음 | 없음 |

## 인프라 API 시그니처

### HazardEffect (struct, `Scripts/Interfaces/HazardEffect.cs`)

```csharp
public enum DamageType { Generic, Spike, SawBlade, Lightning, Fire, CameraFlash }

public struct HazardEffect {
    public float knockbackForce;        // 넉백 속도 (units/s)
    public Vector2 knockbackDirection;  // zero = gravityUp 방향 자동계산
    public float stunDuration;          // 기절 지속시간 (초)
    public DamageType damageType;       // 비주얼/사운드 분기용
}
```

### IHazardSource (`Scripts/Interfaces/IHazardSource.cs`)

```csharp
public interface IHazardSource {
    HazardEffect GetHazardEffect();
    bool IsActive { get; }
}
```

### IPlatformEffect (`Scripts/Interfaces/IPlatformEffect.cs`)

```csharp
public interface IPlatformEffect {
    void OnSlimeAttach(SlimeController slime);   // 착지 시퀀스 완료 후 호출
    void OnSlimeDetach(SlimeController slime);   // 분리 시 호출
    void OnSlimeStay(SlimeController slime, float dt);  // Attached/Charging 매 FixedUpdate
}
```
- `CheckPlatformEffect`는 착지 시퀀스(velocity/state 설정) **완료 후** 호출. JumpPad처럼 `ForceAirborneWithVelocity`로 상태를 되돌릴 수 있음.
- `OnSlimeStay`에서 `ForceAirborneWithVelocity` 호출은 안전. 직접 velocity 쓰기는 비권장.

### IInteractable (`Scripts/Interfaces/IInteractable.cs`)

```csharp
public interface IInteractable {
    bool CanInteract(SlimeController slime);
    void Interact(SlimeController slime);
    string InteractPrompt { get; }
}
```
- `InteractionDetector` (슬라임 부착 컴포넌트) 미구현. 새로 작성 필요.

### IExternalController (`Scripts/Interfaces/IExternalController.cs`)

```csharp
public interface IExternalController {
    void OnTakeControl(SlimeController slime);
    void OnReleaseControl(SlimeController slime);
    void ExternalUpdate(SlimeController slime);
    void ExternalFixedUpdate(SlimeController slime, float dt);
}
```
- `SetOverride` 시 charging 정리, carrier 분리, blockAttach/stunTimer 리셋.
- `ReleaseOverride` 시 gravity stack 클리어, Airborne 복귀.
- **주의**: ReleaseOverride 시 GravityField가 orphan될 수 있음. IExternalController 구현체가 gravity zone 밖으로 슬라임을 이동시킨 후 release하거나, release 후 슬라임 위치에 맞게 gravity zone 재진입 처리 필요.

### EnvironmentalZone (`Scripts/Mechanisms/EnvironmentalZone.cs`)

```csharp
public abstract class EnvironmentalZone : MonoBehaviour {
    protected SlimeController trackedSlime;
    protected virtual void OnSlimeEnter(SlimeController slime) { }  // 진입 시 1회
    protected virtual void OnSlimeExit(SlimeController slime) { }   // 탈출 시 1회
    protected abstract void ApplyEffect(SlimeController slime, float dt);  // 매 FixedUpdate
}
```
- 멀티 콜라이더 중복 진입 방지 (`overlappingColliderCount` 카운터 내장).
- `OnTriggerEnter2D`/`OnTriggerExit2D` 자동 처리. 서브클래스는 3개 메서드만 오버라이드.

### SlimeController 공개 API (Phase 0-4에서 추가된 것)

```csharp
// --- 위치/속도 ---
public Vector2 Position { get; }              // rb.position (보간 아닌 물리 위치)
public Vector2 Velocity { get; }
public void AddExternalVelocity(Vector2 dv);  // 가산 채널 (바람, 부력, 컨베이어)
public void MultiplyVelocity(float factor);   // 곱셈 채널 (드래그, 물 저항)
public void ClampFallSpeed(float max);        // 하향 속도 캡
public void ForceAirborneWithVelocity(Vector2 vel);  // 외부 발사 (JumpPad, Catapult 등)

// --- 위험 ---
public void ApplyHazardEffect(HazardEffect effect);  // → Stunned 상태 진입

// --- 환경 존 ---
public void PushBlockAttach();   // attach 차단 카운터 +1
public void PopBlockAttach();    // attach 차단 카운터 -1 (0 미만 방지)

// --- 중력 ---
public void PushGravityField(GravityField f);
public void PopGravityField(GravityField f);
public Vector2 GravityUp { get; }
public Vector2 GravityRight { get; }
public Vector2 GravityVector { get; }

// --- 오버라이드 ---
public void SetOverride(IExternalController controller);
public void ReleaseOverride(IExternalController controller);
public bool HasOverride { get; }

// --- 텔레포트 ---
public void TeleportTo(Vector2 worldPos, Vector2 newVelocity);  // 전체 상태 리셋

// --- 상태 조회 ---
public SlimeState CurrentState { get; }
public bool IsStunned { get; }
public bool BlockAttach { get; }
```

## 튜닝 철학

이 게임의 핵심은 **commitment (헌신)**. 한번 발사하면 되돌릴 수 없음.

- **즉발 회피 메커닉 없음**: air dash, double jump, jump cancel, wall jump 등 추가하지 않음. 슬라임은 발사 후 중력과 air control만으로 궤도를 조절.
- **차징은 항상 발사로 끝남**: 차징 상태에서 취소하여 Attached로 돌아가는 것 없음. 반드시 발사.
- **점성 슬라임**: 표면에 닿으면 붙음 (바운스 없음). 충돌 에너지를 전부 흡수. stick 시스템으로 착지 관성을 소화.
- **에너지 전환**: 착지 속도를 판정원 크기로 변환하여 연속 점프의 에너지를 보존. W/S 중력 조절로 인한 인플레이션 방지 (shadow speed 공식).
- **위험 오브젝트**: 기절 + 넉백. 체력 시스템 없음 (현재). 기절은 짧은 입력 잠금 + 궤도 이탈. pogostuck/Getting Over It처럼 "떨어지는 것 자체가 벌칙".

새 기능 제안 시 이 원칙과 충돌하는지 확인할 것. 특히 "공중에서 피할 수 있게 해주는" 메커닉은 commitment 원칙을 깨뜨림.

## 구현 난이도 Tier 분류

기준: **"이거 만들 때 SlimeController.cs를 열어야 하나?"** — 열어야 하면 Tier 3, 안 열어도 되면 Tier 1 또는 2.

### 추천 진행 순서

1. **Tier 3 인프라 2개 먼저** — IInteractable(+메모로 검증) → IExternalController(+녹다운 연출로 검증).
2. **Tier 1 일괄** — 인프라 위에서 hazard 변형들, 인터랙터블들, 데코 오브젝트들 한꺼번에.

4. **Tier 3 새 물리 하나씩** — Verlet 줄, 곡선 플랫폼, 큰 슬라임/뱀, 천, 박스, 카메라, 비.

## 1. 물 (Water)

**카테고리**: 환경 존
**상태**: 기본 구현 완료 (WaterZone). 수면 이동/차징은 미구현.

| 참고 코드 | 경로 | 용도 |
|-----------|------|------|
| `WaterZone.cs` | `Scripts/Mechanisms/WaterZone.cs` | 부력, 드래그, 낙하 캡, blockAttach — 이미 구현됨 |
| `EnvironmentalZone.cs` | `Scripts/Mechanisms/EnvironmentalZone.cs` | 트리거 추적 베이스 |
| `DragZone.cs` | `Scripts/Mechanisms/DragZone.cs` | 볼륨 차징 패턴 (`allowCharging`, `EnterVolumeCharging`) |
| `SlimeController.cs` | `Scripts/Controller/SlimeController.cs` | `PushBlockAttach/PopBlockAttach`, `MultiplyVelocity`, `AddExternalVelocity` |
| `SlimeController.Airborne.cs` | `Scripts/Controller/SlimeController.Airborne.cs` | `blockAttachCount` 체크, air control 코드 |

**추가 구현 필요**:
- 수면 감지: 물 트리거 상단 경계에서 슬라임 위치 비교. 수면 근처일 때 AD 이동 + 차징 허용.
- 수면 차징: `DragZone.allowCharging` 패턴 참고. WaterZone에 수면 판정 추가 후 `EnterVolumeCharging` 호출하거나, 수면을 별도 solid collider로 구현.

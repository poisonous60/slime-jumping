# 슬라임 비주얼 튜닝 가이드

슬라임 본체의 비주얼을 튜닝할 때 어떤 값을 어디서 조절해야 하는지 정리. 2D → 3D 마이그레이션 이후(2026-04) 기준.

## 튜닝 포인트 구조

슬라임 비주얼은 두 축에서 튜닝됨:

1. **Material** ([Mat_SlimeBody3D.mat](../SlimeJumping_v2/Assets/Art/Shader/Mat_SlimeBody3D.mat)) — 셰이더 단위 전역 값. 색상·라이팅·vertex displacement 전역 세기.
2. **ScriptableObject** ([SlimeVisualSettings.asset](../SlimeJumping_v2/Assets/Scripts/Settings/)) — C# 쪽 튜너블. 프레임별 변형 값(squash/stretch/sag/breathing 등) 계산에 들어가는 파라미터.

MaterialPropertyBlock로 C#이 매 프레임 쓰는 값은 Inspector에서 보이지만 Play 중에 덮어쓰기 때문에 튜닝 대상이 아님. 튜닝은 항상 위 두 에셋 중 하나에서 함.

## Material — `Mat_SlimeBody3D`

경로: [SlimeJumping_v2/Assets/Art/Shader/Mat_SlimeBody3D.mat](../SlimeJumping_v2/Assets/Art/Shader/Mat_SlimeBody3D.mat)
적용: `Slime/SlimeVisual3d/MeshBaseline/MeshDepthFlatten/SlimeMesh`의 MeshRenderer

### 외형 (색·라이팅)

| 이름 | 타입 | 기본 | 역할 |
|---|---|---|---|
| **Base Color** | Color | 연두 | 슬라임 본체 색 |
| **Rim Color** | Color | 흰색 | 실루엣 라인에 덧붙는 색. 공의 둥근 느낌 살리는 용도 |
| **Rim Power** | Range 0.5–8 | 3 | 클수록 rim이 얇고 뾰족. 작으면 전체적으로 밝아짐 |
| **Toon Steps** | Range 1–6 | 3 | 라이팅을 몇 단계로 끊을지. 1 = smooth gradient, 3~4 = 카툰 밴드 |

### Vertex Displacement 전역 튜닝

| 이름 | 타입 | 기본 | 역할 |
|---|---|---|---|
| **Vertex Displace Scale** | Range 0–2 | 0.5 | 셰이더 변형 **전체**의 세기 배수. Asymmetric squash, ground sink, charge dip, front-compress 모두 여기 곱해짐. 0이면 3D 변형 완전 off → 그냥 공 |
| **Volume Preservation** | Range 0–1 | 0.7 | 두 가지 효과에 동시 적용. ① Asymmetric squash로 한쪽 눌릴 때 반대 방향으로 얼마나 빵빵해지는지 (0 = 작아지기만 함, 1 = 찰진 젤리). ② Velocity stretch로 길어질 때 수직 방향으로 얼마나 얇아지는지 (0 = 두께 유지하며 늘어남 = 부피 증가, 1 = √(1/(1+s))로 얇아지며 부피 보존) |
| **Velocity Front Compress** | Range 0–2 | 1.0 | 이동 중 앞쪽 hemisphere를 안쪽으로 밀어서 눈물방울 만드는 비율. **Stretch 양에 비례**. 0 = symmetric 타원 (앞뒤 같이 늘어남), **1 = stretch와 정확히 상쇄** (front는 제자리, back만 늘어남 = 깔끔한 teardrop), 2 = front에 dimple 생성 |

### MPB로 C#이 덮어쓰는 값 (수정 불필요)

Inspector에서 보이긴 하지만 Play 중이면 1프레임 뒤 C#이 덮어씀. 튜닝은 SlimeVisualSettings 쪽에서.

| 이름 | 설명 |
|---|---|
| `_Asymmetry` | 표면 압착 세기. C#이 `-smoothedSquashStrength * surfaceSquashAsymmetry`로 계산 |
| `_ChargeDip` | 차징 중 dip 깊이. `chargingCurve * chargingDipMax` |
| `_SurfaceNormalWS` | 슬라임 붙어있는 표면의 법선 (world space) |
| `_DipDirWS` | Dip이 파여야 할 방향 (world space) |
| `_VelocityDirWS` | (xyz=velocity 방향, w=속도 norm). Front-compress용 |
| `_VelocityStretchAmount` | **SlimeVisualSettings의 곡선에서 뽑은 stretch 양**. 곡선 편집으로 조절 |

| `impactMinThreshold` | 0.05 | 이 속도 이하 충돌은 impact 무시 |

### Velocity Stretch (C-4) — 2D 아카이브용 + front-compress의 speed reference

2D 스프라이트(아카이브)가 `body.localScale`에 쓰는 값들. 3D 경로는 이 값들 거의 안 씀. 단 `velocityStretchSpeedRef`는 `_VelocityDirWS.w`의 normalize에 쓰이므로 front-compress 타이밍에 영향.

| 이름 | 기본 | 역할 |
|---|---|---|
| `velocityStretchIntensityX/Y` | 0.15 / 0.15 | body.localScale에 들어가는 축별 stretch 세기. **현재 아카이브 sprite만 씀** |
| `velocityStretchSpeedRef` | 15 | "완전 속도" 기준. `_VelocityDirWS.w`의 normalize에 사용됨 (front-compress에 영향) |
| `velocityStretchMaxX/Y` | 0.3 / 0.3 | stretch 상한 clamp |
| `velocityLeanDistance / Max` | 0.05 / 0.08 | 이동 중 뒤로 기우는 offset (body.localPosition) |
| `velocityAxisThreshold` | 1 | 어떤 축이 dominant인지 판정 기준 속도 |
| `velocityStretchCurvePower` | 2 | 2D 아카이브 stretch 커브 지수. **3D와 무관** |
| `velocityStretchCrossDamping` | 0.3 | 축 간 damping. **3D와 무관** |

### Velocity Stretch 3D — 곡선으로 조절하는 3D 전용 영역

3D 셰이더 vertex displacement의 주된 stretch 튜닝 포인트. 여기가 핵심.

| 이름 | 기본 | 역할 |
|---|---|---|
| **`velocityStretch3DSpeedMin`** | 0 | 이 속도(m/s)가 곡선 x=0에 대응. hard clamp 아니라 **기준점**일 뿐. 더 느린 속도도 곡선이 왼쪽으로 뻗어있으면 그 값을 씀 |
| **`velocityStretch3DSpeedMax`** | 15 | 이 속도가 곡선 x=1에 대응. hard clamp 아님. **곡선을 x=1 너머로 그려도 적용됨** — 예: x=2까지 그리면 `2 × speedMax = 30 m/s`에서 그 키 값 샘플 |
| **`velocityStretch3DCurve`** | (0,0) → (1, 0.25) ease | **AnimationCurve 그래프**. x축 = `(rawSpeed - speedMin) / (speedMax - speedMin)` (normalize 안 됨, x>1이나 x<0 다 허용). y = stretch 양 s (보통 0~0.3, 과장하고 싶으면 0.5+). 그래프 클릭해서 키 추가, drag로 조정. 곡선의 양 끝 너머는 Unity 기본 `ClampForever`로 마지막 키 값이 유지 |

곡선 모양 예시:
- **전 속도 구간 고르게 변형**: 기본 (0,0) → (1, 0.25) ease
- **Dead zone (저속에선 안 늘어남)**: (0,0) → (0.5, 0) → (1, 0.3)
- **빨리 찼다가 saturate**: (0,0) → (0.3, 0.25) → (1, 0.3)
- **스텝 함수처럼 급격**: (0,0) → (0.7, 0) → (0.71, 0.3) → (1, 0.3)

#### 최대 stretch 값은 어디?

별도 max 슬라이더 **없음**. 곡선 자체의 **Y 값 중 가장 큰 값**이 max.

**바꾸는 법**: Curve Editor 열고 오른쪽 끝 키 선택 → 하단 "Value" 박스에 숫자 입력하거나 drag. 기본은 (1, 0.25) → 곡선 max = 0.25.

**x=1을 넘어서도 가능**: 곡선을 x=2나 x=3까지 뻗어서 그 영역에 더 큰 y값을 둘 수 있음. x=2는 `2 × speedMax` (= 30 m/s) 속도에 해당. 고속 구간에서만 더 과장되게 하려면 이렇게:
- 예) 키: (0, 0), (1, 0.2), (2.5, 0.6) → 15 m/s까지는 완만, 그 이후 급격히 늘어남.

**실제 화면에서 얼마나 늘어나나 계산**:

```
최종 stretch = curve.y × Mat_SlimeBody3D.VertexDisplaceScale
```

속도 방향 길이 = `1 + 최종 stretch` 배
수직 방향 너비 = `1 / √(1 + 최종 stretch)` 배 (부피 보존)

기본값 기준: `0.25 × 0.5 = 0.125` → 속도 방향으로 12.5% 길어지고 수직으로 5.7% 좁아짐.

**더 과장하고 싶으면**:

| 방법 | 위치 | 효과 범위 |
|---|---|---|
| 곡선 끝점 Y값 올림 (예: 0.25 → 0.4) | `velocityStretch3DCurve` | **velocity stretch만** 세짐 |
| Vertex Displace Scale 올림 (예: 0.5 → 1.0) | Mat_SlimeBody3D | velocity stretch + asymmetric squash + charge dip + front-compress **전부** 같이 세짐 |

Velocity stretch만 조절하고 싶으면 곡선 쪽, 3D 변형 전체의 강도를 손보려면 material 쪽.

### Ground Compensation — 스케일 압축 시 바닥 고정

`body.localScale.y`가 1보다 작아지면 (charging/surface squash/impact/breath 등) 몸이 중심 기준으로 대칭 수축해서 바닥 쪽 edge가 위로 떠오름. 이걸 보정해서 바닥에 계속 붙어있게 하는 메커니즘.

| 이름 | 기본 | 역할 |
|---|---|---|
| `groundCompensationStrength` | 0.5 | `body.localPosition`에 `-surfaceNormal × (1-scale.y) × strength` 추가. **0.5 = 정확 보정** (바닥 edge 고정), 0 = 비활성 (edge가 scale과 함께 뜸), 1 = 과보정 (슬라임이 바닥에 박히는 느낌). visualClearance clamp 이후에 적용돼서 clamp에 의해 0이 되지 않음 |

**왜 0.5가 정확 보정인가**: 몸의 half-height가 SlimeVisual local frame에서 약 0.5 단위라서. 이 값 × yCompress가 scale로 떠오르는 양을 정확히 상쇄. 슬라임 메쉬 크기나 Slime root scale을 바꾸면 이 "정확 값"도 달라지므로 조정 필요.

## 빠른 치트시트

"이것만 조절하고 싶다" 할 때 어디 가야 하는지:

| 원하는 조정 | 어디서 |
|---|---|
| 공 색깔 / 광택 / 카툰 정도 | Mat_SlimeBody3D |
| 전체 3D 변형 약하게 / 강하게 | Mat_SlimeBody3D → Vertex Displace Scale |
| 젤리처럼 빵빵함 ↔ 작아지기만 함 | Mat_SlimeBody3D → Volume Preservation |
| 이동 중 **앞쪽 납작함** (눈물방울 tip) | Mat_SlimeBody3D → Velocity Front Compress |
| **속도별 얼마나 늘어나는지 (그래프)** | SlimeVisualSettings → Velocity Stretch 3D Curve |
| 속도 몇까지 최대 stretch인지 | SlimeVisualSettings → Velocity Stretch 3D Speed Max |
| 저속에서도 변형 시작 vs dead zone | SlimeVisualSettings → Velocity Stretch 3D Speed Min + Curve 좌측 |
| 차징 중 몸 수축량 | SlimeVisualSettings → chargingSquashMax |
| 차징 중 머리 움푹 깊이 | SlimeVisualSettings → chargingDipMax |
| 차징/수축 시 바닥에 붙어있는지 | SlimeVisualSettings → groundCompensationStrength |
| 차징 dip 좌우 bias | SlimeVisualSettings → chargingDipLateralShift |
| 착지 시 bounce 얼마나 오래 | SlimeVisualSettings → impactDuration / impactDecayRate |
| 호흡 얼마나 크게 | SlimeVisualSettings → breathAmplitude |
| 눈이 움직이는 감 | SlimeVisualSettings → Face Tracking / Face Idle Drift |
| 깜빡임 빈도 | SlimeVisualSettings → blinkIntervalMin/Max |
| 경사면에서 흘러내림 | SlimeVisualSettings → gravitySagDistance |

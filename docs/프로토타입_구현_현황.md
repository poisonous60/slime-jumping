## 최근 변경 하이라이트 (2026-04)

- **2026-04-30**: `SnowField` Phase 3 fragment 폴리시 구현 ([snow-field.md](features/platforms/snow-field.md), [Art/Shader/Ground_Quibli_Snow.shader](../SlimeJumping_v2/Assets/Art/Shader/Ground_Quibli_Snow.shader), [Art/Shader/Ground_SnowFragmentInject.hlsl](../SlimeJumping_v2/Assets/Art/Shader/Ground_SnowFragmentInject.hlsl), [Art/Shader/Ground_SnowVertexInject.hlsl](../SlimeJumping_v2/Assets/Art/Shader/Ground_SnowVertexInject.hlsl), [Scripts/Platforms/Snow/SnowMeshBuilder.cs](../SlimeJumping_v2/Assets/Scripts/Platforms/Snow/SnowMeshBuilder.cs)). 약속대로 fragment stage 만 갈아끼움 — `SnowMeshBuilder.AddVert` 가 mesh.uv2.y 를 `0.5f` → `heightRest[origIdx]` 로 채우는 한 줄 변경 외에 vertex 셰이더 / 데이터 모델 / CPU 파이프라인 손 안 댐. (1) **Wrap 전략**: 신규 `SnowFragment` 가 stock `StylizedPassFragment(i.v)` 호출 후 결과에 footprint / fresnel / glitter 폴리시 post-blend. 푸른 그늘 ramp 는 Quibli `_GradientRamp` 슬롯 (NdotL toon ramp) 에 디자이너가 blue→white 그라데이션 텍스처 할당 → 셰이더 작업 0. (2) **Wrapper struct**: `SnowVaryings { Varyings v; float2 snowExtras : TEXCOORD9; }`. Quibli 의 `Varyings` 가 TEXCOORD0~8 까지 조건부로 사용, TEXCOORD9 은 비어 있어 안전. Quibli 파일 한 줄 수정 없이 vert↔frag interpolator 추가. (3) **Carve mask**: `SnowVertex` 가 `staticLightmapUV.y` 의 heightRest 와 비교해서 `mask = saturate(1 - h/heightRest)` 계산 후 `snowExtras.x` 로 fragment 전달. fragment 에서 footprint 영역 검출용. (4) **3개 키워드 (`shader_feature_local_fragment`)**: `_SNOW_FOOTPRINT` (carve 영역 detail texture 블렌드, `mask > 1e-3` gated), `_SNOW_FRESNEL` (그레이징 highlight 가산), `_SNOW_GLITTER` (노이즈 step + view-direction sparkle). 모두 default off 라 Phase 2 와 시각 동치 — 디자이너가 인스펙터 토글로 개별 enable 하고 텍스처 할당. (5) **Quibli 파일 미수정**: `Assets/ThirdParty/Quibli/` read-only 유지. 모든 추가는 클론 셰이더 + 신규 inject HLSL 에서만. Phase 4 (지붕 occlusion) / Phase 5 (슬로프 diffusion) / Phase 6 (sliding carve, leaning B) 는 미구현.

- **2026-04-30**: `SnowField` Phase 2 구현 — 동적 carve + recovery + GPU vertex displacement ([snow-field.md](features/platforms/snow-field.md), [Scripts/Platforms/Snow/](../SlimeJumping_v2/Assets/Scripts/Platforms/Snow/), [Art/Shader/Ground_Quibli_Snow.shader](../SlimeJumping_v2/Assets/Art/Shader/Ground_Quibli_Snow.shader)). (1) **Subdivision** — 신규 `SnowPatchSubdivider` 가 host triangle 을 barycentric 으로 N회 재귀 분할 (인스펙터 `subdivLevels` 0~3, 기본 1). midpoint 의 normal/heightRest 는 endpoint 보간 → 3D 굴곡 보존, vertex 만 dense. low-poly 호스트에서도 carve dip 이 보임. (2) **Mesh 재설계** — `SnowMeshBuilder` 가 un-displaced position + per-vertex tangent (변위 방향, "base" 는 0) + uv2 (heightTex 좌표) 로 mesh emit. 변위 계산은 셰이더가 GPU 에서. AABB 는 maxRest padding 으로 frustum culling 보호. (3) **CPU 데이터 layer** — `SnowStrip.CarveLocal(localImpact, depth, radius)` 가 AABB pre-filter + gaussian falloff (`exp(-4 * (d/r)^2)`) 로 heightCurrent[v] 감소. `TickRecovery(dt, accumRate)` 가 heightRest 로 lerp. dirty flag 로 GPU 업로드 dedupe, 회복 끝나면 active set 에서 제거 → idle FixedUpdate cost 0. (4) **GPU 업로드** — per-strip `Texture2D V × 1 RFloat` (Point Clamp), `SetPixelData + Apply` 로 heightCurrent 미러, `MaterialPropertyBlock` 로 push (material asset 안 더럽힘). (5) **셰이더** — `Ground_Quibli_Snow.shader` 는 Quibli `StylizedLit.shader` 클론, ForwardLit pass 만 vertex pragma 를 `SnowVertex` 래퍼로 교체. inject HLSL (`Ground_SnowVertexInject.hlsl`) 이 `SAMPLE_TEXTURE2D_LOD(_SnowHeightTex, ..., uv2, 0).r` (vertex stage LOD 자동 못 하니 명시) → 옵션 `_SnowSurfaceNoise` multiply → `tangentOS.xyz * h * scale` 변위 → stock `LitPassVertex(input)` 호출. 다른 pass (Outline/ShadowCaster/DepthOnly/...) 는 stock — 그림자/depth 는 un-displaced 모양으로 캐스트 (얇은 carve 면 시각 차이 미미). (6) **Routing** — `SnowFieldRegistry` 정적 `Dictionary<Collider2D, SnowField>`, SnowField OnEnable/OnDisable 에서 `hostCollider → this` 등록. 슬라임 한 개의 `SnowStamper` 가 OnLanded 단일 구독 → registry O(1) 조회 → 매치되면 그 SnowField 만 `HandleLanded(world, depth, radius)` dispatch (N-callback 폭증 회피, TrailColliderRegistry 패턴). (7) **Persistence 없음** — 메모리 only, scene 재로드 시 fresh. snow carve 는 일시 비주얼이라 Trail 처럼 디스크 저장 불필요. Phase 3 (fragment 폴리시: 푸른 ramp / glitter / Fresnel rim / 발자국 detail texture) 미구현.

# 프로토타입 구현 현황

## 아키텍처

단일 원형 콜라이더(`CircleCollider2D`) 기반 2.5D 플랫포머. 소프트바디 없음.
Unity `Rigidbody2D`를 사용하되 `gravityScale = 0`으로 설정하고, 모든 물리를 수동 velocity 관리로 처리.

### 속도 필드 규약 (Velocity Field Contract)

**세 가지 계층:**

| 필드 | 타입 | 역할 |
|------|------|------|
| `velocity` | `Vector2` (내부) | 컨트롤러가 관리하는 의도된 운동. 상태별 의미가 다름 (아래 참조) |
| `rb.linearVelocity` | `Vector2` (Unity) | 매 FixedUpdate 끝에 `velocity + platformVel * carrierFriction`으로 덮어씀. 이동 플랫폼 동기화용. **직접 읽지 말 것** — 항상 `velocity`를 소스로 삼음 |
| `slideSpeed`, `crawlVelocity` | `float` (스칼라) | 접선 방향 스칼라. 각각 독립 계산 (slide = 중력 접선 분해, crawl = 입력 가속 모델) |

**상태별 `velocity` 의미:**

- **Attached / Charging**: `surfaceTangent * (slideSpeed + crawlVelocity)`. 매 FixedUpdate 끝에 재구성. "접선 방향 현재 속도"를 담음.
- **Airborne**: 키네마틱 중력 적분 결과. 공중에서의 실제 궤적 속도.

**파생 규칙:**

- **접선 속도 추출**: `Vector2.Dot(velocity, surfaceTangent)` 또는 `slideSpeed + crawlVelocity` 둘 다 유효 (Attached/Charging 한정).
- **상태 전환 시 리셋**: Airborne→Attached 전환에서 `velocity = Vector2.zero`. 이유: "점성 슬라임은 운동량 흡수" 원칙 + 다음 FixedUpdateAttached가 slideSpeed/crawlVelocity로 재구성하기 때문.
- **Hop 예외**: `velocity += surfaceNormal * hopPower`로 법선 성분 주입 후 Airborne 전환. 이 프레임만 velocity가 접선 규약을 벗어남.
- **Charge 진입 시 관성 처리**: `impactTangentSpeed`에 현재 접선 속도 스칼라 저장 후 `stickDeccelTimer`로 접선 공간 lerp 감속. `chargeEntryCrawl`은 별도 캡처 (하이퍼 대시용).

### Stick 시스템 타이머 규약

세 개의 독립 타이머가 협력하여 착지→슬라이드 전환을 제어. 서로 직접 간섭하지 않음.

| 타이머 | 방향 | 트리거 | 역할 |
|--------|------|--------|------|
| `stickTimer` | 카운트다운 | 착지 시 또는 Charge Entry Grace 시 설정 | > 0이면 슬라이드 억제. 감소만 함. 0 도달 시 슬라이드 재개 |
| `stickDeccelTimer` | 카운트업 (0 → `stickDecelerationTime`) | 착지 시 또는 Charge Entry Grace 시 0으로 리셋 | `impactTangentSpeed` → 0 lerp 후 현재 `surfaceTangent`에 재투영. 착지/차징 진입 관성의 시각적 감속 담당 |
| `slideRampTimer` | 카운트업 (0 → `stickSlideTransitionRampTime`) | stick 만료 시 (`wasStuck` 플래그로 감지) 0으로 리셋 | 슬라이드 속도를 0→전체로 부드럽게 ramp-up |

**동작 시퀀스:**

```
착지/차징 진입
  ├─ stickTimer = N (착지: 충돌 속도 비례, 차징: += chargeEntryStickBonus)
  ├─ stickDeccelTimer = 0 (감속 시작)
  ├─ impactTangentSpeed = 현재 접선 속도 (부호 있는 스칼라)
  └─ wasStuck = true
  
[stickDeccelTimer 구간: 0~stickDecelerationTime]
  velocity = surfaceTangent * Lerp(impactTangentSpeed, 0, t)   ← 접선 공간 감속 (곡면에서도 표면 추종)
  
[stickTimer 잔여 구간]
  velocity = zero                             ← 정지 상태 유지, 슬라이드 억제
  
[stickTimer 만료 → wasStuck 감지]
  slideRampTimer = 0                          ← ramp 시작
  
[slideRampTimer 구간]
  slideSpeed *= Clamp01(slideRampTimer / rampTime)  ← 0→전체 부드러운 전환
```

**핵심 주의점:** `stickTimer`를 연장해도 `stickDeccelTimer`나 `slideSpeed`에 직접 영향 없음. stickTimer는 "억제 기간"만 제어하고, 속도 감속은 `stickDeccelTimer`가 독립적으로 처리. 혼동하기 쉬우나 셋은 완전히 분리된 역할.

## 상태 머신

4개 상태: **Attached**, **Charging**, **Airborne**, **Stunned**.

**상태 전환 중앙화**: 모든 `currentState` 변경은 `ChangeState(newState, intentional)` 함수를 통해 수행. `intentional=true`는 Launch/Hop 등 의도적 이탈에 사용 (디바운스 카운터 리셋). 그 외 전환은 디바운스 토글로 카운트.

**IExternalController override**: `_override` 필드가 non-null이면 Update/FixedUpdate가 override에 위임됨. SetOverride/ReleaseOverride로 제어. 뱀/큰 슬라임 삼킴, 벤치, 퍼즐 오버레이, 시네마틱에 사용. Override 전용 API: `OverrideVelocity(Vector2)` — HasOverride==true일 때만 사용 가능, 그 외 호출 시 LogError. (OverridePosition은 #5/#27/#31 구현 시 추가 예정.)

**OnLanded 이벤트**: `event Action<Vector2, Vector2> OnLanded` — (position, surfaceNormal). Airborne→Attached 또는 Airborne→Charging(에너지 전환) 전환 시 발화. SnapToSurface 이후, CheckPlatformEffect 이전. LandingDustSpawner가 구독.

**부착 디바운스**: 짧은 시간(`attachToggleWindow`) 내 상태 전환이 `attachToggleLockoutThreshold`에 도달하면 `attachLockoutDuration` 동안 착지 전환 차단. Lockout 중 중력/에어 컨트롤은 정상, 표면 접촉 시 법선 속도만 상쇄. 모서리/코너 오실레이션 방지.

### Attached (표면 부착)

모든 각도의 표면에 부착. `OverlapCircleNonAlloc` + `ClosestPoint`로 표면 감지 및 geometric primary 선택. 천장(`surfaceUp < ceilingThreshold`)은 부착 불가.

**크롤링 (A/D 이동)**:
- 입력을 표면 접선 방향으로 투영.
- 가속/감속 모델: `MoveTowards(crawlVelocity, targetSpeed, accel/decel * dt)`. 최대 속도 초과 시 `crawlOverspeedDeceleration` 적용.
- 입력 시 빠르게 가속, 놓으면 감속 (관성 조절 가능).

**스틱 타이머 (착지 후 표면 고정)**:
- 공중에서 벽/급경사에 착지 시 **충돌 속도에 비례한 시간** 동안 슬라이드 없이 표면에 고정.
- 계산식: `t = 1 - 1 / (1 + impactSpeed * stickSpeedScale)` → `stickTimer = Lerp(minStickDuration, maxStickDuration, t)`
- 수렴 커브: 속도가 아무리 커져도 maxStickDuration을 초과하지 않음.
- `stickSlopeThreshold` 이상 = 바닥(고정 없음). 미만 = 벽/급경사(동적 고정 적용).
- **적용 시점**: Airborne → Attached, Airborne → Charging (착지 경로만), Attached → Charging (Charge Entry Grace).
- **Charge Entry Grace**: Attached에서 Space로 Charging 진입 시 `stickTimer += chargeEntryStickBonus` (가산). 현재 접선 속도를 `impactTangentSpeed` 스칼라로 저장하고 `stickDeccelTimer`를 재시작하여 접선 공간에서 부드럽게 감속. `slideRampTimer` 리셋 + `wasStuck = true`로 만료 시 ramp-up 보장.
- Attached에서는 고정 중 크롤 속도에 `stickCrawlMultiplier`(기본 0.2) 배율 적용 (0=완전 차단, 1=정상). Charging에서는 고정 중에도 조준 가능.
- **스틱 감속 (관성 표현)**: 고정 시작 시 착지 접선 속도를 `impactTangentSpeed` 스칼라로 저장하고, `stickDecelerationTime` 동안 접선 공간에서 Lerp로 0까지 감속 (`velocity = surfaceTangent * Lerp(impactTangentSpeed, 0, t)`). 매 프레임 현재 `surfaceTangent`에 재투영하여 곡면에서도 표면 추종. Attached/Charging 모두 동일하게 적용.
- **스틱→슬라이드 전환**: 스틱 만료 시 `slideRampTimer`를 리셋(`wasStuck` 플래그로 만료 감지). 슬라이드가 0→전체로 `stickSlideTransitionRampTime` 동안 부드럽게 ramp-up. Attached/Charging 모두 적용.

**표면 미끄러짐 (중력)**:
- 중력을 표면 접선/법선으로 분해.
- 접선 성분 = 미끄러짐 속도. 법선 성분 = 표면이 상쇄.
- 속도 누적 없음 — 매 프레임 각도에서 직접 계산.
- `slideThreshold` 이하 접선 중력: 미끄러짐 없음 (완만한 경사 보호).
- `slideResistance`: slideSpeed에서 빼서 완만한 경사는 많이 감속, 급경사는 적게 감속.
- 크롤링은 원래 중력 접선 전체와 싸움 (resistance 적용 전 값).

**그라운드 대시 (S 순간 부스트)**:
- Attached 상태에서 A/D 크롤 중 S를 누르면 `crawlVelocity`에 순간 impulse 추가.
- 실제 점프 아님 — 표면 부착 유지.
- S pressed(rising edge)에만 발동, 홀드 시 반복 안 함.
- **입력 버퍼**: S를 먼저 누르고 `groundDashInputBuffer`(0.1초) 안에 A/D 입력 시에도 발동.
- **코요테 버퍼**: Airborne에서 S 누르면 버퍼 저장, 착지 시 A/D 홀드 중이면 발동.
- **쿨타임**: `groundDashCooldown`(0.3초) 동안 재발동 불가. wall-clock 기반 (`Update()`에서 tick).
- **기울기 제한**: `groundDashAngleMin`(30°)~`groundDashAngleMax`(60°) 구간에서 1→0 보간. 평지=풀 부스트, 급경사=불가.
- `SurfaceMaterial.groundDashScale`로 표면별 추가 배율 적용 (기본 1.0).
- **헬퍼 함수**: `ApplyGroundDash(float inputSign)` — `FixedUpdateAttached`의 대시 로직과 착지 버퍼 경로에서 공유.
- **속도 감쇠 (Gradual falloff)**: 같은 방향 crawl 속도가 `dashFalloffStart`(5) 이상이면 impulse가 선형 감소, `dashFalloffEnd`(13)에서 0. 반대 방향 dash는 제약 없음. Hop-dash chain exploit 방지.

**홉 (W 표면 점프)**:
- Attached 상태에서 W를 누르면 표면 법선 방향으로 작은 점프 (`surfaceNormal * hopPower`).
- 기존 접선 운동량 보존: `velocity += Vector2.up * hopPower`. 표면 법선과 무관하게 항상 위쪽으로 점프. 스틱 중에는 `velocity = Vector2.up * hopPower` (잔여 속도 무시).
- `crawlVelocity = 0` (접선 운동량은 velocity 필드로 이관).
- **홉 모멘텀**: 스틱이 아닌 상태에서 홉마다 A/D 입력 방향으로 접선 속도에 `hopMomentumBonus`(1.5) 가산. `hopMomentumMaxSpeed`(20)에서 캡. 입력 중립이면 보너스 미적용. 반복 홉으로 점진적 가속 가능 (버니홉).
- **입력 지연 처리 (Deferred flag)**: 입력 콜백은 `hopRequested = true`만 set. 실제 `Hop()`은 `FixedUpdateAttached` 끝에서 velocity 재구성 완료 후 호출. 이로써 Hop()이 항상 신선한 velocity, surfaceTangent, surfaceNormal 위에서 동작.
- **홉 착지 속도 보존**: `preserveLandingVelocity` 플래그 → `ComputeLandingCrawlVelocity` 헬퍼가 retention을 `hopLandingRetention`(기본 1.0)으로 강제. 두 착지 경로(Attached/Charging)에서 동일 헬퍼 사용, 코드 중복 없음.
- **쿨타임**: `hopCooldown`(0.1초). wall-clock 기반.

**홉 입력 버퍼 (코요테)**:
- Airborne 상태에서 W 누르면 `hopBufferTimer`에 저장.
- Airborne → Attached 착지 시 버퍼 활성이면:
  1. `preserveLandingVelocity = true` → retention 강제 → `crawlVelocity`에 air tangent 100% 보존.
  2. `velocity = surfaceTangent * crawlVelocity`로 재구성 (착지 코드가 velocity를 0으로 만들었으므로).
  3. `stickTimer = 0` (stick 분기 우회 — 각도 무관 일관 동작).
  4. `Hop()` 즉시 호출.
- 버퍼 hop은 `hopCooldown`을 우회 (의도적 — 벽 등반 사용처).

**하이퍼 대시 (Dash → Charge → Launch 콤보)**:
- 그라운드 대시 후 즉시 차징하면, 대시 운동량이 발사에 합산.
- **캡처 시점**: `HandleJumpPressed`(Attached → Charging)에서 `chargeEntryCrawl = crawlVelocity` 저장. 차징 중 `crawlDeceleration`이 시각적 감속을 처리하지만, 캡처 값은 보존됨.
- **발사 시**: `velocity += lastSurfaceTangent * chargeEntryCrawl * tangentInheritanceFactor`.
- **홉 경로**: Hop 시 `chargeEntryCrawl = crawlVelocity` 캡처. 홉 후 에너지 전환 착지 시 crawl boost 사용 가능.
- **에너지 전환 감쇠**: `conversionRatio = activeChargeRadius / chargeRadius`로 전환 크기 측정. `hyperDashConversionDampingMin`(1.2) 이하면 100% 유지, `hyperDashConversionDampingMax`(2.0) 이상이면 0%, 사이는 선형 보간.
- **코요테 탄젠트 캐싱**: `lastSurfaceTangent`를 `lastSurfaceNormal`과 함께 캐싱. 코요테 중 표면 이탈 시에도 `Launch()`가 올바른 접선 방향 사용.

**착지 입력 우선순위**: Charging > W(Hop) > S(Dash). 상위 입력이 하위 버퍼를 소비.

**최종 속도**: `finalTangent = slideSpeed + crawlVelocity`.

**표면 속성 배율 적용**: 크롤링 속도/가속/감속, 슬라이드 저항/중력에 `SurfaceModifiers` 배율이 곱해짐. Charging 상태의 슬라이드/감속에도 동일 적용.

**표면 스냅**: 2-Phase 방식. Phase A: `OverlapCircleNonAlloc` + `ClosestPoint` 기반 다중 콜라이더 depenetration (push only, 최대 3회 반복). Phase B: primary surface와 거리 초과 시에만 pull. 코너에서 Minkowski boundary 자동 수렴. 표면 선택은 5-step geometric fallback (천장 필터 > 침투 깊이 > 입력 방향 > continuity > gravity).

**천장 프리필터 (Step 1.5)**: active contact에 천장(`surfaceUp < ceilingThreshold`)과 비천장이 혼재할 경우, 천장 contact를 step 2-5 후보에서 제외. 전부 천장이면 필터 미적용 (기존 동작 유지). 코너에서 미세한 침투 깊이 차이로 천장이 primary가 되어 영구 Airborne 고정되는 버그 방지.

### Charging (차징 — 판정원 모델)

스페이스 홀드 → 슬라임 중심에 판정원 생성. 조준점(aimOffset)이 원 안에서 이동.

**진입 경로 2가지:**
1. **일반 차징**: Attached 상태에서 스페이스 누름 → 표면 스냅 + 코요테 타이머 초기화 → 조준점 중심에서 시작, 자동 드리프트로 바깥 이동.
2. **에너지 전환**: 공중에서 스페이스 홀드한 채로 표면 충돌 → Attached 건너뛰고 바로 Charging 진입. 착지 접선 속도를 `impactTangentSpeed` 스칼라로 저장하여 접선 공간 스틱 감속 적용.

**조준점 이동 (판정원 안)**:
- 자동 드리프트: 현재 방향으로 반지름 증가 (각도 고정, 길이만 성장).
- WASD: 2D 가속으로 조준점 이동.
- aimOffset은 슬라임 기준 상대 좌표 — 슬라임이 미끄러져도 판정원은 따라감.

**발사 트리거**:
1. 스페이스 릴리즈 → 수동 발사.
2. 조준점이 판정원 가장자리 도달 → `chargeFullAimTime`(0.1초) 유예 후 자동 발사. 유예 중 파워 확정(가장자리 고정), WASD로 방향만 변경 가능. 유예 중 스페이스 릴리즈 시 즉시 발사.

**발사 계산**:
```
ratio = aimOffset.magnitude / chargeRadius
curvedRatio = ratio ^ chargeCurveExponent
# 일반 차징:
power = minLaunchPower + curvedRatio * (baseLaunchPower - minLaunchPower)
# 에너지 전환 (확장된 판정원):
power = curvedRatio * baseLaunchPower
direction = -aimOffset.normalized  (압축 반대 방향)
```
`chargeCurveExponent`로 비선형 파워 커브 조절. 일반 차징에서는 `minLaunchPower`로 최소 발사력 보장. 에너지 전환에서는 확장된 판정원이 큰 반지름을 제공하므로 `minLaunchPower` 미적용.

**곡면 법선 추적**: 곡면에서 크롤 시 법선이 프레임마다 변하는데, `chargeNormalFollowSpeed`(rad/s)로 최대 회전 속도를 제한하여 aimOffset/driftDirection이 부드럽게 회전. 평지에서는 영향 없음.

**차징 중 표면 선택**: 차징 중에는 `CheckSurface`에 `inputX=0`을 전달하여 입력 기반 tiebreaker를 비활성화. WASD가 표면 선택에 영향을 주지 않아 곡면에서 법선이 튀지 않음.

**차징 중 슬라임 물리**: 벽에서 미끄러짐은 그대로 적용 (시간 압박). 판정원 조작은 독립. 단, 중력 접선 성분에 `chargingSlideGravityScale`(기본 0.5)을 곱하여 차징 중 슬라이드 속도를 감쇠. Charge Entry Grace의 스틱 만료 후 완만한 재가속 보장.

**발사 시 접선 속도 합산 (하이퍼 대시)**:
- `hyperDashDeduction` 이하의 crawl 속도는 무시하고, 초과분(excess)만 boost에 반영: `excess = Max(0, |chargeEntryCrawl| - hyperDashDeduction)`. 0으로 설정하면 전체 crawl 속도가 반영됨.
- `velocity += lastSurfaceTangent * sign(chargeEntryCrawl) * excess * tangentInheritanceFactor`.
- `lastSurfaceTangent`: 코요테 중에도 올바른 접선 방향 보장 (표면 이탈 시 기본값(0,1) 대신 캐싱값 사용).
- `chargeEntryCrawl`: 차징 진입 시점의 crawlVelocity (차징 중 감속과 독립).

**차징 표면 프로브 히스테리시스**: 곡면/모서리에서 SurfaceProbe가 1~2 프레임 감지 실패 시, `chargingSurfaceProbeGraceFrames`(3) 동안 캐시된 표면 데이터(법선, 접선, 콜라이더)로 valid 분기 유지. grace 초과 시에만 coyote 진입. `surfaceProbeMissFrames` 카운터로 추적, 유효 프레임마다 0 리셋. `isTouchingSurface`는 건드리지 않음.

**발사 후 처리**:
- 발사 표면 콜라이더 무시 (clearance 또는 timeout으로 해제).
- 0.05초 입력 무시 윈도우.

### Airborne (공중)

**중력**: 키네마틱. `velocity.y += gravity * dt`. 상승/하강 비대칭 중력: 상승 시 `risingGravityScale`, 하강 시 `fallingGravityScale` 곱셈 적용.

**에어 컨트롤 활성 조건**: `velocity.y <= apexThreshold`(기본 0)일 때만 활성. 상승 중에는 W/S + A/D 모두 비활성.

**에어 컨트롤 (A/D)**: 수평 가속/감속 모델. 속도 캡 초과 시 브레이킹만 허용.
```
targetVx = inputX * airMaxHorizontalSpeed
velocity.x = MoveTowards(velocity.x, targetVx, accel/decel * dt)
```

**중력 조절 (W/S, last-input-wins)**: W 홀드 = 체공 (`floatGravityScale`), S 홀드 = 급강하 (`diveGravityScale`). 상승/하강 비대칭 중력 (`risingGravityScale`, `fallingGravityScale`) 곱셈 적용.

**착지 분기**:
- **천장 (`surfaceUp < ceilingReattachThreshold`)**: 부착 안 함. 법선 속도만 상쇄, Airborne 유지.
- **스페이스 홀드**: 에너지 전환 → Charging 직행.
- **스페이스 미홀드**: Attached 전환. 바닥(`surfaceUp >= stickSlopeThreshold`)이면 스틱 없음 + `conversionCount` 리셋. 벽/급경사면 스틱 타이머 적용.

**착지 시 상대속도 계산**: 착지 코드에서 `relativeVel = velocity - landingPlatformVel`을 계산하여 tangentSpeed, normalSpeed, impactVelocity, retention, redirect를 모두 상대속도 기준으로 처리. 이동 플랫폼에서 속도 이중 적용 방지. `landingPlatformVel`은 선형 + 회전 접선 속도 포함 (`GetSurfaceVelocity` 헬퍼).

**착지 속도 보존 (landingVelocityRetention)**: 착지 시 접선 상대속도의 일부를 `crawlVelocity`에 주입. 0=즉시정지(기본), 0.8=빙판. 기존 crawl 감속 시스템이 자연 감속 처리. `ComputeLandingCrawlVelocity` 헬퍼가 두 착지 경로(Attached/Charging)에서 공유. `preserveLandingVelocity` 플래그 활성 시 `hopLandingRetention`(기본 1.0)으로 강제 — hop 착지 전용.

**스틱 지속시간 배율 (stickDurationMultiplier)**: 표면마다 stickTimer에 곱하는 배율. 0=빙판(스틱 없음), 1=기본. retention과 함께 써야 불연속 없음.

**충돌 방향 전환 (impactRedirectRatio)**: 착지 시 법선 충돌 속도의 일부를 접선 방향으로 전환. 빙판 벽에 수평 충돌 → 위로 미끄러져 올라감. 표면 각도에 따라 자동 스케일링 (`redirectScale = 1 - |Dot(normal, up)|`): 바닥에서는 0, 벽에서는 1.

### Stunned (기절)

위험 오브젝트(가시, 톱날, 번개 등)에 의해 진입. `ApplyHazardEffect(HazardEffect)` 호출로 진입.

- 입력 잠금: 모든 입력 핸들러 early-return.
- 물리: 중력 1x (W/S 조절 없음, 비대칭 없음). 표면 접촉 시 법선 속도만 상쇄 (Airborne 천장 충돌과 동일). Attached/Charging 전환 차단.
- 타이머: `stunTimer` 카운트다운. 만료 시 Airborne으로 전환 (`intentional: true`).
- i-frame: 기절 중 추가 `ApplyHazardEffect` 무시. (TODO: Phase 5+에서 time-based i-frame으로 분리 가능.)
- 외부 힘: `AddExternalVelocity` (바람 등) 정상 적용 (Airborne과 동일 분기).

**진입 시 정리**: 차징 비주얼 숨김, 캐리어 분리, 플랫폼 효과 해제, 표면 modifier 리셋, 모든 타이머/크롤/에임 초기화, `RegisterOverlapping` 호출.

## 에너지 전환 (벽 충돌 에너지 전환)

공중에서 스페이스를 미리 누르고 표면에 충돌하면, 운동량이 차징 에너지로 전환된다.

**흐름:**
1. 에너지 보존 공식으로 충돌 속도 계산: `shadowSpeedSq = launchSpeed² + 2|gravity|·Δh` (W/S 중력 조절이 전환량을 부풀리지 않도록).
2. `effectiveRate = √initialConversionRate × (chargeRadius / baseLaunchPower)`.
3. `spawnDistance = impactSpeed × effectiveRate`.
4. 연속 전환 배율 적용: `conversionCount > 0`이면 `spawnDistance *= subsequentConversionRate`.
5. 낙하 전환 보너스: `launchSpeed == 0`(점프 없이 낙하)이면 `spawnDistance *= notJumpConversionBonus`.
6. 판정원 반지름보다 크면 확장된 판정원 사용.
7. `impactTangentSpeed = tangentSpeed` (스틱 감속용 착지 관성 스칼라 저장).
8. `velocity = 0`, `crawlVelocity = ComputeLandingCrawlVelocity(effectiveTangent, landingAngle)` (표면 속성에 따라 착지 관성 보존).
9. `aimOffset = Vector2.zero` (조준점 중심에서 시작, 자동 드리프트로 이동).
10. `chargeEntryCrawl *= hyperDashRetention` (전환 크기에 비례하여 crawl boost 감쇠. DampingMin 이하면 100% 유지, DampingMax 이상이면 0%).
11. `conversionCount++` (연속 전환 카운트 증가). `conversionCount`는 바닥 착지(Attached)에서만 리셋 — wall chain에서 `subsequentConversionRate` 유지는 의도된 동작.

**강한 충돌 (`spawnDistance > chargeRadius`)**:
- 판정원 반지름이 `spawnDistance`까지 **확장**됨 (`activeChargeRadius = max(spawnDistance, chargeRadius)`).
- 조준점은 중심에서 시작, 자동 드리프트로 확장된 판정원 가장자리까지 이동.
- 확장된 판정원에서 `aimDriftRadiusScale`만큼 드리프트 속도 보상.

**약한 충돌 (`spawnDistance <= chargeRadius`)**:
- 일반 차징과 동일 (기본 판정원 크기, 조준점 중심에서 시작).

## 표면 감지

`CheckSurface`: `OverlapCircleNonAlloc` + `ClosestPoint` 기반 표면 감지 및 geometric primary 선택.

**콜라이더 수집**: `OverlapCircleNonAlloc(pos, slimeRadius + detectRange, mask)`로 주변 콜라이더 수집. `ignoredColliders` 필터링.

**법선·거리 계산**: 각 콜라이더에 대해:
- `collider.ClosestPoint(pos)`로 접촉점 계산
- `(pos - closest).normalized`로 법선 계산 (항상 슬라임 쪽을 가리킴)
- `(pos - closest).magnitude`로 거리 계산
- 깊은 침투 시(`toSlime.sqrMagnitude < 0.0001f`) 콜라이더 skip (fallback normal 생성하지 않음)

**Active contacts**: `distance ≤ slimeRadius + contactSkin`인 콜라이더 집합.

**5-step geometric primary selection** (복수 active contacts 시):
1. **단일 contact** → 유일한 것 (99% 케이스)
2. **침투 우선**: 침투된 contact(`distance < slimeRadius`) 중 가장 깊은 것. Motion-aware 신호 — weight 없음.
3. **입력 방향 tiebreaker**: `-normal · inputDir` 최대값 (명확한 차이 필요). **Charging 중에는 inputX=0 전달로 비활성화.**
4. **Continuity**: prevCollider가 active set에 있으면 유지.
5. **Gravity alignment**: `normal · up` 최대값 (fresh landing fallback).

**천장 판정 (히스테리시스)**: 탈출과 진입에 다른 임계값 사용. 각도 기반 설정(`ceilingAngle`, `ceilingReattachAngle`)을 `cos(angle)`로 변환하여 Dot product와 비교.
- **탈출** (Attached/Charging → Airborne): 표면 각도 ≥ `ceilingAngle`(107°)이면 떨어짐.
- **진입** (Airborne → Attached/Charging): 표면 각도 ≤ `ceilingReattachAngle`(101°)이어야 부착.
- 사이 구간(101° ~ 107°)에서는 현재 상태 유지 → 구체 표면 크롤링 시 상태 떨림 방지.

**ignoredCollider 시스템**: 발사한 표면을 일시적으로 무시.

## 동적 플랫폼 시스템

PlatformMotor + PlatformCarrier 패턴. 플랫폼은 자신의 움직임만 책임지고, 슬라임은 플랫폼 종류를 모름.

### 스크립트 구조

| 스크립트 | 네임스페이스 | 역할 |
|---------|-------------|------|
| `PlatformMotor.cs` | SlimeJumping.Platforms | 추상 베이스. Kinematic Rigidbody2D, MovePosition/MoveRotation. Delta/Velocity 노출 |
| `WaypointPlatform.cs` | SlimeJumping.Platforms | 웨이포인트 이동. localWaypoints, speed, easing, loop/ping-pong |
| `RotatingPlatform.cs` | SlimeJumping.Platforms | 연속 회전 또는 sin 기반 왕복 (oscillate) |
| `PendulumPlatform.cs` | SlimeJumping.Platforms | 진자 운동 + 세 층의 라이더 영향: (a) 착지 임펄스, (b) 위치 토크(줄 스윙), (c) 판자 flex 스프링-댐퍼. `swayRatio`로 판자/줄 커플링 제어. `ropes` (LineRenderer[]) 배열에 연결된 각 로프를 매 LateUpdate에 world-space로 갱신. 각 로프의 Z는 자신의 transform Z를 따라 서로 다른 depth 배치 가능. 프리팹 구조: 빈 루트 → Board(PendulumPlatform+Rigidbody2D) + Rope(LineRenderer) 자식 |

### 슬라임 통합 방식

플랫폼 속도를 `rb.linearVelocity`에 합산하여 interpolation과 충돌하지 않는 velocity 기반 동기화.

```
rb.linearVelocity = velocity + platformVelocity * carrierFriction
```

- `rb.position` 직접 조작 없음 — interpolation 보장.
- `GetEffectiveVelocity()`: 선형 속도 + 회전 접선 속도(arm rotation) 포함.
- `carrierFriction` (SurfaceModifiers): 0=얼음(플랫폼 움직여도 안 따라감), 1=완전 전달.
- 발사 시 플랫폼 속도 상속: `velocity += carrier.GetEffectiveVelocity() * carrierFriction`.
- 착지 시 `GetSurfaceVelocity(surfaceCollider)`로 선형+회전 속도를 직접 계산 (Airborne에서는 carrier가 Detach 상태이므로). 모든 착지 계산(tangentSpeed, normalSpeed, impactTangentSpeed, retention, redirect)이 이 상대속도 기준.

### 실행 순서

`PlatformMotor` (`[DefaultExecutionOrder(-100)]`) → `SlimeController` (default 0).
PlatformMotor가 MovePosition 큐잉 → SlimeController가 Velocity 읽어서 linearVelocity에 합산 → 물리 스텝에서 동시 이동.

## 표면 속성 시스템

SurfaceMaterial (ScriptableObject) + SurfaceTag (MonoBehaviour) + SurfaceModifiers (구조체) 패턴. 표면마다 물리 배율을 커스터마이징.

### 구조

- `SurfaceMaterial`: ScriptableObject 에셋. "빙판", "진흙" 등을 만들어 공유.
- `SurfaceTag`: 기본값과 다른 표면 오브젝트에만 부착하는 마커 컴포넌트.
- `SurfaceModifiers`: SlimeController가 읽는 구조체. SlimeController는 `SurfaceMaterial`을 직접 참조하지 않음.
- SurfaceTag가 없는 표면은 모든 배율 1.0 (기존 동작 그대로).

### AngleScaledValue

모든 SurfaceMaterial 파라미터는 `AngleScaledValue` 타입. 표면 각도에 따라 값을 보간.

```
struct AngleScaledValue {
    baseValue   // angleMin 이하에서의 값
    fullValue   // angleMax 이상에서의 값
    angleMin    // 보간 시작 각도 (0° = 바닥)
    angleMax    // 보간 끝 각도 (90° = 벽)
}
```

- `Evaluate(surfaceAngle)`: `InverseLerp(angleMin, angleMax, surfaceAngle)` → `Lerp(baseValue, fullValue, t)`.
- `Constant(v)`: 모든 각도에서 동일 값 (기본 동작, 하위 호환).

### 조회 타이밍

- **착지 시** (`carrier.Attach`와 동일 시점): `GetComponentInParent<SurfaceTag>()` 한 번 조회 → 캐싱.
- **Airborne 전환 시**: `SurfaceModifiers.Default`로 리셋.
- **표면 전환 감지**: `FixedUpdate`에서 `surfaceCollider != prevSurfaceCollider`일 때 `carrier.Attach` + `UpdateSurfaceModifiers` 재호출 (히스테리시스 경계에서 표면이 바뀌는 경우 대응).

### 파라미터 (SurfaceMaterial — 모�� AngleScaledValue)

## 비주얼 시스템 (절차적 변형)

`SlimeVisual.cs` — `LateUpdate`에서 모든 비주얼을 제어. 물리(FixedUpdate)와 완전 분리.

### Deformation Axis (body.up)

| 상태 | target_up | 비고 |
|------|-----------|------|
| Attached/Charging | `surfaceNormal` | 표면 법선 방향. Slerp 보간 |
| Airborne | `Vector2.up` (world up) | 축 분해 stretch가 world X/Y 기준이므로 world up 필수 |

`deformAxisSlerpSpeed`(15)로 보간. body.up은 "변형 축 정렬" 용도 — 방사 대칭 이미지라 회전 자체는 보이지 않음.

### Face 추종 (C-1)

**Face 위치 오프셋 (회전 아님):**

| 상태 | interest 계산 | 비고 |
|------|--------------|------|
| Charging | `-AimDirection * faceChargingScale` | aim 각도 즉시 반응 |
| Attached/Airborne | `Velocity * faceOffsetScale` | 이동 방향 쏠림, 정지 시 자동 중앙 복귀 |

- 방향 잔상: 정지 시 `faceLingerDecay`로 서서히 감쇠.
- 아이들 드리프트: `tanh(sin(t) * sharpness)` X축 사코드 패턴.
- 깜빡임: `eyes_closed.png` 스왑, 랜덤 간격(3~7초)마다 0.1초간.

### 충격 squash (C-2)

Airborne→Attached/Charging 전환 시 착지 충격 시각화.
- 법선 성분 속도 기반 강도: `Clamp01(Abs(Dot(lastNonZeroVelocity, surfaceNormal)) / impactSpeedReference)`.
- 감쇠 코사인 곡선: `e^(-decay * t) * cos(freq * PI * t)`. 초기 squash → 탄성 overshoot → settle.
- Fast layer (SmoothDamp 바깥) → 날카로운 반응 유지.

### 속도 stretch (C-4)

**표면**: `speed / velocityStretchSpeedRef`에 비례. body.up=surfaceNormal → velocity가 X축 방향 → `(+stretch, -stretch)`.

**Airborne**: 축 분해 방식. velocity를 중력 방향(Y)과 수평 방향(X)으로 독립 분해. `velocityStretchCurvePower`로 비선형 커브, `velocityStretchCrossDamping`으로 교차 축 감쇠.

**Velocity lean**: body center를 velocity 반대 방향으로 오프셋. "앞은 고정, 뒤가 끌려옴" 효과. Slow layer.

### 표면 squash + 중력 sag (C-5)

- 법선 성분(`Dot(gravity, normal)`): 표면을 누르는 힘 → `(+squash, -squash)`. 평지=최대, 벽=0.
- 접선 성분(`Dot(gravity, tangent)`): 흘러내리는 힘 → pivot offset (sag). 평지=0, 벽=최대.
- `smoothedSquashStrength`를 별도 SmoothDamp로 관리 → scale과 shader asymmetry가 동일 곡선.

### 호흡 (C-6)

`sin(breathPhase * 2PI) * breathAmplitude` 미세 진동. Fast layer. 모든 상태에서 항상 활성.

### 비대칭 셰이더

Shader Graph (`SlimeBody.shadergraph`) — Sprite Lit 기반.
- `_Asymmetry`: UV.y 리맵으로 아래쪽 절반 압축 → 달걀 모양. `smoothedSquashStrength * surfaceSquashAsymmetry`. 평지=최대, 벽=대칭, Airborne=대칭.
- `_ChargeDip`: 차징 중 하단 인덴트. `chargingCurve * chargingDipMax`.
- `_DipCenterU`: dip 중심 좌우 이동. `Dot(aim, tangent) * chargingDipLateralShift`. 대각선 aim 시 비대칭.

### 차징 비주얼 (C-7)

`ChargingLaunchSpeed` (예상 발사 속도)에서 `chargingCurve` (0~1) 계산.

- **Squash** (slow layer): `chargingCurve * chargingSquashMax`. 표면에 눌려붙는 느낌.
- **Tremor** (fast layer): `chargingTremorThreshold` 이상에서 활성. `sin` 기반 고주파 진동, `t²`로 진폭 증가. "위험한 에너지 축적" 긴장감.
- **Offset** (slow layer): surface push (`-surfaceNormal * chargingCurve * chargingPushMax`) + aim pull (`-AimDirection * bodyChargingAimPull`). 슬링샷 모델.
- aim pull은 chargingCurve 미적용 — 각도 변화에 즉시 반응. `SmoothDamp`가 부드러움 담당.

### 변형 합성 공식

```
// Slow layer: SmoothDamp
targetScale = (1,1) + surfaceSquash(C-5) + velocityStretch(C-4) + chargingSquash(C-7)
smoothedScale = SmoothDamp(prev, targetScale, deformSmoothTime)

// Fast layer: 직접 합산
finalScale = smoothedScale + impactOverlay(C-2) + breathing(C-6) + chargingTremor(C-7)
finalScale = Clamp(0.4, 1.8)

// Offset: SmoothDamp
targetOffset = gravitySag(C-5) + velocityLean(C-4) + chargingOffset(C-7)
smoothedOffset = SmoothDamp(prev, targetOffset, offsetSmoothTime)

// Visual clearance clamp (코너 침범 방지)
// smoothedOffset/finalScale를 직접 수정하지 않고 appliedOffset/appliedScale 로컬 복사본만 클램프
// sag 방향으로 레이캐스트 → 인접 표면까지 clearance 측정 → ratio 기반 축소
appliedOffset = smoothedOffset * ratio
appliedScale.x = 1 + max(0, deltaX) * ratio  // 양의 확장분만 클램프

// Shader
MaterialPropertyBlock → _Asymmetry, _ChargeDip, _DipCenterU
```

### 공개 API

- `SlimeController.AimDirection` — 발사 방향 (`-aimOffset.normalized`, fallback: `surfaceNormal`)
- `SlimeController.ChargingProgress` — 차징 진행도 0~1 (`aimOffset.magnitude / activeChargeRadius`)
- `SlimeController.ChargingLaunchSpeed` — 현재 aimOffset 기반 예상 발사 속도

### TeleportTo 규약

`SlimeController.TeleportTo(Vector2 worldPos, Vector2 newVelocity)`:
- `rb.position = worldPos`, `velocity = newVelocity`, `rb.linearVelocity = newVelocity`
- `ChangeState(Airborne, intentional: true)` — 디바운스 카운터 리셋
- Charging 초기화: aimOffset, chargeFullAimTimer, coyoteTimer, activeChargeRadius, driftDirection, chargeVisual.Hide()
- Carrier: Detach + surfaceMod 기본값
- IgnoredColliderList: Clear (이전 위치 무관)
- 타이머 전체 리셋: stick, stickDeccel, slideRamp, crawlVelocity, chargeEntryCrawl, postLaunch, hop/dash 버퍼
- externalDeltaV = Vector2.zero (이전 위치의 외부 힘 잔여분 초기화)
- 에너지 추적: launchSpeed = |newVelocity|, launchHeight = worldPos.y, conversionCount = 0

### Portal 속도 변환

```
vIn      = dot(velocity, -entry.OutNormal)
vTangent = dot(velocity, entry.Tangent)
newV     = exit.OutNormal * vIn + exit.Tangent * vTangent
exitPos  = exit.position + exit.OutNormal * exitOffset
```

프레임 규약: `transform.right` = 바깥 법선, `transform.up` = 접선. 벽 배치 시 right가 벽에서 바깥으로 향하도록 Z축 회전.

### 메커니즘 카테고리 (6분류)

1. **환경 존** (지속 효과) — EnvironmentalZone 베이스. 물, 비, 바람, 중력장, DragZone.
2. **위험** (즉발+경직) — IHazardSource + ApplyHazardEffect + Stunned 상태. 가시, 톱날, 번개, 파이어볼, 카메라, 칼.
3. **플랫폼 효과** (착지/접촉 트리거) — IPlatformEffect 컴포넌트. 컨베이어, 점프대, 투석기, 탄력 나뭇가지.
4. **인터랙터블** (W키) — IInteractable + InteractionDetector. 침대, TV, 퍼즐 문, 메모.
5. **오버라이드 컨트롤러** (슬라임 전체 탈취) — IExternalController. 삼킴, 앉기, 퍼즐 오버레이, 시네마틱.
6. **소프트 피직스 오브젝트** (자체 시뮬) — SlimeController 무접촉. Verlet 로프, 천, 적 AI.

### 외부 속도 파이프라인 (Two-Channel Model)

환경 기믹이 슬라임 속도에 기여하는 두 채널:

**가산 채널 — `AddExternalVelocity(Vector2 deltaV)`**
- `externalDeltaV` (Vector2): 매 FixedUpdate 소비/초기화. 호출측이 `acceleration * dt`를 넘김.
- 적용 시점: state switch 이후, `rb.linearVelocity` 대입 직전.
- Airborne/Stunned → velocity에 직접 가산.
- Attached/Charging → `surfaceTangent`에 투영 후 가산 (법선 성분 제거, 스냅 지터 방지).
- 사용처: WindZone2D, ConveyorBelt, WaterZone(부력).

**곱셈 채널 — `MultiplyVelocity(float factor)` / `ApplyDragFactor(float factor)`**
- `velocity *= factor` 직접 적용. 프레임당 호출.
- `ApplyDragFactor`는 DragZone 호환용 별칭. `MultiplyVelocity`가 정식 이름.
- 사용처: DragZone(감속), WaterZone(드래그).

**부가 — `ClampFallSpeed(float max)`**
- 곱셈 채널의 특수 케이스. 하향 속도를 max로 제한.
- 사용처: DragZone, WaterZone.

### WindZone2D

Trigger volume 기반 지속 바람 기믹. `OnTriggerEnter2D`/`OnTriggerExit2D`로 슬라임 추적. `FixedUpdate`에서 `AddExternalVelocity` 호출.

- `windAcceleration` (Vector2): 방향+세기. 월드 기준 units/s².
- `terminalSpeed`: 바람 방향 최대 속도. 선형 감쇠 `falloff = clamp01(1 - v_along / terminal)`.
- `airborneMultiplier` / `attachedMultiplier` / `chargingMultiplier`: 상태별 배율 (Airborne 1.0, Attached 0.7, Charging 0.2).
- 비주얼: 자식 ParticleSystem (Stretched Billboard + Velocity over Lifetime).

### DragZone (감속/모래 볼륨)

Trigger volume 기반 감속 + 볼륨 차징 기믹. WindZone2D와 동일 패턴 (`OnTriggerEnter2D`/`OnTriggerExit2D` + `FixedUpdate`).

- `entryMultiplier` (0.3): 진입 시 1회 velocity 곱. `slime.OnDragZoneEnter(this)`.
- `exitMultiplier` (3.33): 탈출 시 1회 velocity 곱. 하향 Y는 보존. `slime.OnDragZoneExit(this)`.
- `launchMultiplier` (0.3): 볼륨 안 발사 시 velocity 곱. exit와 조합되어 최종 속도 결정.
- `dragFactor` (0.3): 매 프레임 지수 감쇠. `slime.ApplyDragFactor(Pow(factor, dt))`.
- `maxFallSpeed` (5): 매 프레임 Y 음수 cap. `slime.ClampFallSpeed(max)`.
- `allowCharging` (false): true이면 Airborne에서 볼륨 내 차징 진입 허용.

SlimeController 연동:
- `CurrentDragZone` (DragZone 참조): DragZone이 Enter/Exit에서 설정/해제.
- `IsInChargeVolume` (property): `CurrentDragZone != null && CurrentDragZone.allowCharging`.
- `isVolumeCharging` (bool): 볼륨 차징 중 표면 물리 비활성화 플래그.
- 볼륨 차징 진입: `EnterVolumeCharging()` — Airborne + jump press + IsInChargeVolume.
- 볼륨 차징 취소: `CancelChargingToAirborne()` — 볼륨 이탈 시 또는 코요테 만료.
- 파일: `Mechanisms/DragZone.cs`.

### PushDoor (밀어서 여는 문)

살롱 도어 스타일 경첩 문. 콜라이더는 X축 평행이동, 비주얼은 분리된 3D 메시가 asin 매핑으로 회전.

- Push: 접촉 기반. 슬라임이 닿아있으면 `pushAccel`로 일정 가속, `pushMaxSpeed`로 속도 캡. velocity 무관, 위치로 방향 결정.
- Return: 접촉 없으면 스프링-댐퍼 복원. `force = -returnStiffness * x - returnDamping * v`.
- Push/Return 완전 분리: pushAccel은 열림 속도만, returnStiffness/returnDamping은 닫힘만 결정.
- 통과: `|currentX| >= openThreshold` (= `doorDepth * sin(openAngleDeg)`) → 콜라이더 비활성. `minOpenTime` 동안 재활성화 보류. 이후 overlap 체크 후 재활성화.
- 비주얼: `theta = -asin(currentX / doorDepth)`. `doorDepth = transform.position.z + hingeOffset.z`. VisualPivot의 localPosition에 currentX 보정으로 힌지 월드 고정.
- Carrier: PlatformMotor 상속. translation 델타로 carrier에 자동 전파.
- 시그니처 변경: `PlatformMotor.ApplyRiderInfluence`에 `Vector2 riderVelocity` 파라미터 추가. PlatformCarrier가 `SlimeController.Velocity` 전달. PushDoor는 riderVelocity 미사용 (접촉 기반).
- 파일: `Platforms/PushDoor.cs`.

### GravityField (중력 방향 치환 구간)

Force field이 아님. zone 내부에서 "아래" 방향만 교체. 중력 크기(`|settings.gravity|`)는 유지.

**Effective Gravity 아키텍처**:
- `SlimeController`에 `gravityUp`/`gravityRight`/`GravityVector` 필드 추가. 매 `FixedUpdate` 첫머리 1회 계산.
- `gravityFieldStack` (LIFO): GravityField가 `OnTriggerEnter2D`/`Exit2D`로 push/pop. 스택 최상위의 GetDownDirection 사용.
- 스택 비면 `gravityUp = Vector2.up` (world gravity).
- 모든 물리/비주얼 코드가 `Vector2.up` 대신 `gravityUp`을, `new Vector2(0, gravity)` 대신 `GravityVector`를 참조.
- `SurfaceProbe.CheckSurface`와 `GetSurfaceAngle`에 `gravityUp`/`gravityRight` 파라미터 추가. 천장 필터, 입력 타이브레이커, 중력 정렬 모두 effective gravity 기준.

**모드**:
- Fixed: `localDownDirection` 벡터 (상수). 임의 collider 모양 OK.
- Radial: `localPivot` 기준 방향. `invertDirection`으로 안/밖 전환.

**Gravity-axis 분해 패턴** (air control, ClampFallSpeed, DragZoneExit):
```csharp
float gravComponent = Vector2.Dot(velocity, gravityUp);
float hComponent = Vector2.Dot(velocity, gravityRight);
velocity = gravityUp * gravComponent + gravityRight * hComponent;
```

- `TeleportTo`에서 `gravityFieldStack.Clear()` + gravityUp/gravityRight 리셋.
- `launchHeight`는 `Vector2.Dot(rb.position, gravityUp)`으로 중력축 투영.
- Layer 9: GravityField. groundLayer에 포함 안 됨.
- 파일: `Mechanisms/GravityField.cs`.

### SpikeHazard (가시)

IHazardSource 구현. 트리거 콜라이더. `OnTriggerEnter2D`에서 `slime.ApplyHazardEffect(effect)` 호출.

- `knockbackForce`: 넉백 속도 (units/s).
- `stunDuration`: 기절 지속시간 (초).
- 방향 모드:
  - `useLocalUp = true`: 가시의 `transform.up` 방향으로 넉백.
  - `useLocalUp = false` + `redirectTarget` 없음: 가시 중심 → 슬라임 방향으로 자동 계산.
  - `useLocalUp = false` + `redirectTarget` 지정: 슬라임 → 타겟 좌표 방향으로 넉백.
- 파일: `Mechanisms/SpikeHazard.cs`.

### JumpPad (점프대)

IPlatformEffect 구현. 착지 시 `ForceAirborneWithVelocity` 호출로 즉시 발사.

- `launchForce`: 발사 속도 (units/s).
- `launchDirection`: 로컬 스페이스 발사 방향 (자동 정규화).
- `cooldown`: 재발동 방지 쿨다운 (초).
- `CheckPlatformEffect`는 착지 시퀀스 완료 후 호출 → `ForceAirborneWithVelocity`가 상태를 Airborne으로 되돌림.
- 파일: `Mechanisms/JumpPad.cs`.

### ConveyorBelt (컨베이어벨트)

IPlatformEffect 구현. `OnSlimeStay`에서 `AddExternalVelocity` 호출. SlimeController가 Attached/Charging에서 surfaceTangent에 자동 투영.

- `speed`: 가속도 (units/s²).
- `localDirection`: 로컬 스페이스 방향.
- `terminalSpeed`: 최대 속도. 선형 감쇠.
- 파일: `Mechanisms/ConveyorBelt.cs`.

### EnvironmentalZone (환경 존 베이스)

추상 MonoBehaviour. `OnTriggerEnter2D`/`OnTriggerExit2D`로 슬라임 추적. `FixedUpdate`에서 `ApplyEffect(slime, dt)` 호출.

- 가상 메서드: `OnSlimeEnter`, `OnSlimeExit`, `ApplyEffect` (abstract).
- 기존 WindZone2D, DragZone은 아직 미이관 (동일 패턴이나 독립 구현).
- 파일: `Mechanisms/EnvironmentalZone.cs`.

### WaterZone (물)

EnvironmentalZone 구현. 부력 + 드래그 + 낙하 캡 + attach 차단.

- `entryMultiplier` (0.4): 진입 시 속도 곱.
- `exitMultiplier` (2.5): 탈출 시 속도 곱.
- `dragFactor` (0.4): 초당 속도 잔류율. `MultiplyVelocity(Pow(dragFactor, dt))`.
- `buoyancy` (12): 상향 가속도. `AddExternalVelocity(gravityUp * buoyancy * dt)`.
- `maxFallSpeed` (4): 하향 속도 캡. `ClampFallSpeed`.
- `blockAttach` (true): 물 안에서 표면 부착 차단. `PushBlockAttach`/`PopBlockAttach` 카운터 기반. Airborne 착지 시 + Attached/Charging FixedUpdate에서 체크. 차단 시 법선 속도만 상쇄하고 air control은 유지.
- 파일: `Mechanisms/WaterZone.cs`.

### IPlatformEffect 라이프사이클

- `CheckPlatformEffect(surfaceCollider)`: 착지 시 `GetComponentInParent<IPlatformEffect>()` 조회. 변경 시 `OnSlimeDetach`/`OnSlimeAttach` 호출.
- `OnSlimeStay(slime, dt)`: `FixedUpdateAttached`와 `FixedUpdateCharging`(표면 위)에서 매 프레임 호출.
- `ClearPlatformEffect()`: 분리 시 호출 (표면 이탈, Launch, Hop, Teleport, 기절, 오버라이드).
- `CheckPlatformEffect`는 착지 시퀀스(velocity/state 설정) 완료 후 호출. JumpPad처럼 즉시 `ForceAirborneWithVelocity`를 호출해 상태를 되돌릴 수 있음.

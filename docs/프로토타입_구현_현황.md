# 프로토타입 구현 현황 (인덱스)

> **문서 분할 (2026-04-24):** 기능별로 세분화하여 [features/](features/) 아래로 재구성. 이 파일은 현황 요약 + 링크 허브.

## 아키텍처 상수

- **Unity 6000.3.11f1**, URP.
- 단일 `CircleCollider2D` 기반 2.5D 플랫포머. 소프트바디 없음.
- `Rigidbody2D` + `gravityScale = 0` + 수동 velocity 관리.
- ScriptableObject 기반 튜닝 (`SlimeSettings`, `SlimeVisualSettings`, `SurfaceMaterial`).
- 슬라임 비주얼: **3D 메쉬 기반** (`Slime/SlimeVisual3d`). 2D 스프라이트 구성은 아카이브(비활성).

## 최근 변경 하이라이트 (2026-04)

- **2026-04-24**: 오디오 시스템 체계화 — `SoundService.PlayBgm/StopBgm` + 2-source 크로스페이드(`AudioSource.volume` 선형 lerp), `StageBgmPlayer` 컴포넌트, `SoundService`의 `DontDestroyOnLoad` 전환(양 씬에 prefab 배치 + 중복 가드). 옵션 패널에 BGM / UI 슬라이더 추가 (Player / World SFX와 함께 총 4개 볼륨 슬라이더). `AudioSourceMixerGroupValidator` 에디터 스크립트 추가: 씬/프리팹 저장 시 `outputAudioMixerGroup == null`인 `AudioSource` 콘솔 경고 (저장은 차단 안 함). `CLAUDE.md`에 Audio System 규칙 섹션 신설.
- **2026-04-24**: 옵션 패널 SFX 볼륨 슬라이더를 Player / World 둘로 분리 (`GameOptions.PlayerSfxVolume` = `SFX_Slime`, `WorldSfxVolume` = `SFX_Environment` + `SFX_Object`). 믹서에 서브그룹 노출 파라미터 `SFXSlimeVolume` / `SFXEnvironmentVolume` / `SFXObjectVolume` 추가. 기존 단일 SFX 볼륨 `PlayerPrefs` 키(`opt.sfxVolume`)는 최초 로드 시 양쪽 슬라이더로 마이그레이션.
- **2026-04-24**: 옵션 패널에 Background Camera On/Off 토글 추가 (`GameOptions.BackgroundCameraEnabled` + `BackgroundCameraOption`). Off 시 BG 카메라의 CullingMask 를 0 으로 만들어 Background 레이어 오브젝트는 숨기고 SolidColor 클리어(스테이지 백드롭 색)는 유지. 동시에 TranslucentImageSource 의 Preview/enabled 를 끄면 블러 blit 비용도 제거됨. (BG 카메라까지 끄면 Main 이 ClearFlags=Nothing 이라 화면이 비고, TIS만 disable 하면 Preview 패스가 stale 블러 텍스처를 fullscreen 으로 출력해 이전 프레임이 멈춰 보임.)
- **2026-04-24**: 눈 내리는 VFX 추가 (`Assets/Prebs/VFX/Snow.prefab`). Kenney Particle Pack `circle_05` 스프라이트 + URP Particles/Unlit 알파 블렌드. Main Camera 자식으로 붙여 카메라 따라가지만 시뮬레이션은 World 공간 (맵 전체에 자연스러운 드리프트).
- **2026-04-23**: 배경 상시 Blur (TranslucentImage), 옵션 패널 (데모용 ESC 토글), 해상도 독립 슬라임 크기 (FOV 세로 해상도 비례).
- **2026-04-22**: Two-Ramp Y Blend 셰이더 (스테이지 경계 메시가 두 Quibli 그라데이션 보간).
- **2026-04-17**: 진행 트레일 시스템 (월드 RT + 로컬 RT, R8 mask + persistence).
- **2026-04-16**: SlimeBody_Quibli 셰이더 스택 (StylizedLit + SlimeDeform.hlsl 5-스테이지). WaterZone v3 셰이더 (UniversalForward + Universal2D + caustics).
- **2026-04**: 슬라임 본체 3D 메쉬 전환 (Icosphere/Sphere). 2D 스프라이트 아카이브.

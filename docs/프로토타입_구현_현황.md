## 최근 변경 하이라이트 (2026-04)

- **2026-04-25**: `TerrainShape2D` 인-에디터 지형 메시 작성 툴 v0 (프로토타입). MonoBehaviour + `[CustomEditor]` + `OnSceneGUI` 패턴 (DeformablePlatformEditor 와 동일 컨벤션). 외곽선(Outline) / 내부 점(Interior) / 강제 엣지(Edges) 3개 툴 모드, FlatOnly / AutoSubdivide / Manual 3개 분할 모드. **알고리즘**: 외곽선 곡선 = Catmull-Rom (per-point `smooth` 토글), 삼각분할 = Triangle.NET (constrained Delaunay). FlatOnly = `-p` (외곽선만 채움), AutoSubdivide = `-p -q -a` (Ruppert refinement, Steiner 자동 추가), Manual = `-p -YY` (사용자 점·엣지만 보존). 외곽선/강제엣지는 PSLG segment 로 입력. 좌표 안정성은 quantize(1e-6) 기반 dictionary 로 라운드트립. 인터랙션: Outline=드래그/Shift-edge-insert/Ctrl-delete/per-point smooth 토글, Interior=Shift-inside-add/PositionHandle XYZ 드래그/Ctrl-delete (Manual 모드에서만), Edges=두 정점 클릭으로 강제엣지 추가/Ctrl-edge 로 제거 (Manual 모드에서만). 외곽선은 항상 Z=0 평면에 머무르므로 기존 `MeshToCollider2DGenerator`(Z=0 cross-section) 가 그대로 콜라이더 생성. **Save Mesh As Asset** 으로 `Assets/GeneratedMeshes/` 에 저장. **라이선스 주의**: Triangle.NET 은 Shewchuk Triangle 의 불명확한 라이선스를 상속하므로 상업 출시 전 대체 검토 필요. 위치: [Scripts/Platforms/TerrainShape/](../SlimeJumping_v2/Assets/Scripts/Platforms/TerrainShape/), [Scripts/Editor/TerrainShape/](../SlimeJumping_v2/Assets/Scripts/Editor/TerrainShape/), [Plugins/TriangleNet/](../SlimeJumping_v2/Assets/Plugins/TriangleNet/).
- **2026-04-25**: `MediaInteractable_PhonographV2` 추가 (축음기 v2, [tier1-interactables.md](features/mechanisms/tier1-interactables.md)). E 입력 시 공유 `GramophonePanel` (UILayer.Modal, `UIManager.Open` 경유로 슬라임 입력 게이트) 을 띄우고, 트랙은 `PhonographPlaylist` ScriptableObject (displayName / clip / volume) 에서 읽어 ScrollRect + VerticalLayoutGroup + ContentSizeFitter 로 동적 렌더. 트랙 선택 → 패널 fade-out → `OnAfterClose` 에서 `SoundService.PlayBgm(clip, crossfadeSeconds, volume)` + 니들 Z-회전 틸트 + 디스크 스핀업 코루틴. "Stop music" 은 `SoundService.StopBgm(fadeSeconds)` + 스핀다운. 콜라이더는 루트 고정, 회전은 `discTransform`(자식 pivot) 과 `needleArm` 만 — 비주얼/콜라이더 분리 원칙 준수. 여러 축음기 지원 (BGM 채널은 글로벌 싱글이라 다른 축음기에서 재생 시 기존 곡이 크로스페이드로 대체됨). v1 (`MediaInteractable_Phonograph`) 과 병존. 에디터 빌더: `Tools → SlimeJumping → UI → Build or Rebuild GramophonePanel Prefab`, 테스트 씬: `SlimeJumping → Interaction → Setup PhonographV2 Test`. `UISceneWirer.WireMainScene` 에 자동 인스턴스화 추가.
- **2026-04-25**: `ClothField` 통과 커튼 v1 구현 ([cloth.md](features/mechanisms/cloth.md)). 3축 자유 회전 + 실제 메쉬 두께(front/back/측면 스커트)를 가진 Verlet 2D 그리드. 슬라임 충돌은 **로컬 프레임 3D 구(sphere) 충돌** 로 처리 — 매 구속 반복마다 (1) 구 안에 있는 질점을 외향 push, (2) structural + shear 엣지의 closest point 가 구 안이면 그 세그먼트도 외향 push (cellSize ≪ 슬라임 지름인 환경에서 인접 질점 사이 메쉬 변이 슬라임을 가로질러 보이는 현상 방지). 바닥 충돌은 `Physics2D.OverlapCircle`+`Collider2D.ClosestPoint` (월드 XY, Collider2D 무한 Z). 드래그 3중 안전장치(초당 캡 / 누적 클램프 / Charging·Attached 면제)로 commitment 원칙 보호. 자체 바람(`windAccelerationWorld` + Perlin 난류). `SlimeJumping/Mechanism/Setup Cloth Test` 메뉴로 doorway/wall 3종 빌드. Rope.cs 는 손대지 않고 Verlet 패턴만 복사. Shader는 URP Unlit 자체 작성(양면 + 핀 마스크 알파 + 소소한 shimmer).

## 1. Architecture Overview

```
SlimeSoftBody (MonoBehaviour)          -- Owns the physics pipeline
  ├── 7 SlimeNode (plain class)        -- Position, Velocity, Force, Mass
  ├── 15 SlimeSpring (plain class)     -- Stiffness, Damping, RestLength
  ├── event OnApplyExternalForces      -- Pre-integration force callback
  └── event OnPostCollision            -- Post-collision contact callback

AdhesionSystem (MonoBehaviour)         -- Surface sticking
  ├── subscribes OnApplyExternalForces -- Apply adhesion spring forces
  └── subscribes OnPostCollision       -- Detect new contacts (fresh data)

SlimeController (MonoBehaviour)        -- State machine
  ├── subscribes OnApplyExternalForces -- Air control forces
  ├── subscribes OnPostCollision       -- Landing detection
  ├── ChargeLaunchSystem (plain class) -- Charge timing + launch impulse
  ├── AirControl (plain class)         -- Horizontal redirect
  └── SurfaceCrawler (plain class)     -- Surface movement

SlimeMeshGenerator (MonoBehaviour)     -- Catmull-Rom spline rendering
SlimeCameraTarget (MonoBehaviour)      -- Smoothed follow for Cinemachine
SlimeDebugDraw (MonoBehaviour)         -- Gizmo visualization
SlimeInputReader (MonoBehaviour)       -- New Input System with consume pattern

SlimePhysicsSettings (ScriptableObject)   -- Spring omega/zeta, collision params
SlimeGameplaySettings (ScriptableObject)  -- Adhesion, charge, air control, crawl
```

### Physics Pipeline (SlimeSoftBody.FixedUpdate)

```
1. Clear all node forces
2. Apply gravity (asymmetric: 2.5x when falling + airborne)
3. Apply spring forces (Hooke's law + directional damping)
4. Apply pressure forces (Shoelace area -> ideal gas -> outward normals)
5. >>> OnApplyExternalForces (adhesion springs, air control) <<<
6. Integrate (semi-implicit Euler, velocity clamped to 30 m/s)
7. Resolve collisions (2-phase: OverlapPoint CCD + OverlapCircle surface)
8. >>> OnPostCollision (adhesion detection, landing check) <<<
```

## 2. Soft Body System

### Node Layout
- **7 nodes**: 1 center (mass 2.0) + 6 perimeter (mass 1.0)
- Perimeter nodes at 60-degree intervals, radius 0.5 units

### Spring Topology (15 total)
| Type | Count | Connects | Purpose |
|------|-------|----------|---------|
| Radial | 6 | Center <-> Perimeter | Overall shape |
| Edge | 6 | Adjacent perimeter | Outer form |
| Cross-brace | 3 | Opposite perimeter (N1<->N4, N2<->N5, N3<->N6) | Prevent inversion |

### Spring Parameterization
Uses **omega/zeta** (frequency + damping ratio) instead of raw k/c:
```
k = mass * (2*PI*freq)^2
c = 2 * mass * 2*PI*freq * zeta
```
Stability limit: k * dt^2 < 1 -> max k ~2500 at 50Hz

### Default Tuning
| Parameter | Value |
|-----------|-------|
| Radial spring | 4 Hz, zeta 0.3 |
| Edge spring | 3 Hz, zeta 0.25 |
| Cross-brace | 2 Hz, zeta 0.5 |
| Pressure constant | 40 |
| Gravity scale | 1.0 |
| Node collision radius | 0.03 |
| Restitution | 0.3 |
| Friction | 0.8 |

### Volume Preservation
Shoelace formula computes perimeter polygon area. Pressure = constant / area.
Force applied as outward normals on each edge, split between edge endpoints.

## 3. Collision System

### 2-Phase Resolution (CollisionResolver.cs)

**Phase 1 -- Deep Penetration (OverlapPoint)**
- Detects if node center is inside any collider
- If previous position was outside: `Linecast` from previous to current finds exact crossing point
- Fallback: AABB bounds-based minimum-penetration push-out
- Handles tunneling from high-velocity impacts

**Phase 2 -- Surface Contact (OverlapCircle)**
- Detects if node radius overlaps any collider surface
- `ClosestPoint` gives the surface point; push out along normal
- Skips nodes already handled in Phase 1

### Anti-Tunneling
- `SlimeNode.PreviousPosition` saved before each integration step
- Velocity clamped to 30 m/s in `Integrate()`
- Detection radius = `nodeRadius * 2` for surface contacts

## 4. Adhesion System

### Lifecycle
1. **Detection** (OnPostCollision): When a perimeter node touches a surface, create an `AdhesionPoint` (anchor position + surface normal)
2. **Force Application** (OnApplyExternalForces): Spring force pulls node toward anchor. Damping applied as counter-force (`F = -c * v * m`)
3. **Break**: If spring force exceeds `AdhesionMaxForce`, adhesion point is removed
4. **Clear**: On launch, all adhesions are cleared

### Stability
```
Stability = adhered perimeter nodes / total perimeter nodes (6)
```
Affects launch power: `actualPower = basePower * stability`

### Center-of-Mass Offset
```
CoM Offset = all-nodes center of mass - average adhered node position
```
Affects launch direction deviation.

### Default Parameters
| Parameter | Value |
|-----------|-------|
| Adhesion stiffness | 150 |
| Adhesion max force | 80 |
| Velocity damping | 0.92 |

## 5. Input System

### SlimeInputReader
- References `InputActionAsset` directly (no code generation)
- Actions used: `Player/Move` (Vector2), `Player/Jump` (Button)
- **Consume pattern**: `ConsumeJumpPressed()` / `ConsumeJumpReleased()` called from `FixedUpdate` to prevent dropped inputs between Update/FixedUpdate timing

### Direction Quantization
Move input snapped to 9 directions (8 cardinal/diagonal + zero).
Threshold: 0.3 per axis.

## 6. Controller State Machine

```
         Jump pressed
Attached ──────────────► Charging
    ▲                        │
    │ land (OnPostCollision) │ Jump released OR adhesion lost
    │                        ▼
    ◄──────────────────  Airborne
```

### State Behaviors

**Attached**
- Adhesion validity checked FIRST (prevents charging from midair)
- WASD = surface crawling (velocity blending, not position teleport)
- Space = transition to Charging

**Charging**
- Charge accumulates over time (cubic power curve)
- WASD direction locked at start (0.1s buffer for late input)
- Cannot cancel -- commitment mechanic
- Safety: if adhesion breaks, force-launch with `max(lastStability, 0.15)`

**Airborne**
- A/D = horizontal redirect (cannot accelerate in same direction)
- Asymmetric gravity: 2.5x when descending
- Landing detected in OnPostCollision (works even during post-launch ignore)

### Launch Formula
```
actualPower = baseLaunchPower * chargeCurve(t/maxDuration) * stability
actualDirection = normalize(aimDirection + comOffset * deviationCoeff)
impulse = actualDirection * actualPower
```
Center node gets 70% of impulse, perimeter splits 30%.

## 7. Rendering

### Catmull-Rom Mesh (SlimeMeshGenerator)
- 6 perimeter nodes -> 8 segments each -> **48 perimeter vertices + 1 center = 49 total**
- Triangle fan with **CW winding** (normals face -Z toward camera)
- Manual normals set to `Vector3.back`
- UV: center (0.5, 0.5), perimeter by angle

### Interpolation
- Uses `SlimeNode.PreviousPosition` and `Position` directly (no separate FixedUpdate)
- Lerp factor: `(Time.time - Time.fixedTime) / Time.fixedDeltaTime`
- Eliminates execution-order race conditions

### Material
- URP Unlit, green (0.2, 0.9, 0.3), opaque
- Created at scene setup time

## 10. Known Issues & Limitations

### Current Limitations
- AABB-based collision fallback assumes axis-aligned box colliders (no rotated/polygon support)
- Perimeter count must be even (enforced at runtime)
- No visual effects (squash/stretch, particles, trails)
- Camera not set up with Cinemachine yet (manual positioning)
- Main Camera settings reset on play (not saved in scene)

### Design Decisions
- Custom physics (not Rigidbody2D) for full control over spring-mass behavior
- `OnApplyExternalForces` / `OnPostCollision` event pattern eliminates all FixedUpdate ordering races
- Velocity damping implemented as counter-force (`F = -c*v*m`) not direct velocity mutation, to keep the force callback side-effect-free
- CCD via `Linecast` from `PreviousPosition` prevents tunneling at high speeds

# SlimeJumping — 핵심 메커닉 설계 v3

## 컨셉

**점성 슬라임** — 모든 표면에 달라붙는 것이 자연 상태. 이동은 크롤링과 차징 발사로 수행.  
WASD + Space 키로 조작. 모든 시간 단위는 **초(seconds)** 기준.

**장르 지향**: 점프킹, Egging On, 셀레스트, 구구피자 계열의 정밀 플랫포머.  
슬라임의 소프트바디 비주얼은 게임플레이에 영향을 주지 않는다. 조작 반응성과 예측 가능성이 최우선.

---

## 1. 구현 아키텍처 — 2단계 분리

### Phase 1: 단일 원형 콜라이더 플랫포머 (핵심)

게임플레이 전체가 **원 하나**로 동작한다.

- 충돌 판정, 이동, 차징, 발사, 에어 컨트롤, 벽 부착, 드리프트 — 전부 단일 원형 콜라이더 기반.
- 소프트바디 없이도 모든 메커닉이 완전히 동작함.
- 점프킹/셀레스트와 동일한 구조.

### Phase 2: 소프트바디 비주얼 오버레이 (후순위)

Phase 1이 완성된 후 비주얼로 얹는 레이어.

- 중심 1개 + 주변 6개 노드가 스프링으로 연결된 링 구조.
- 주변 노드는 중심 노드의 Position을 읽어서 스프링으로 따라감. **중심 → 주변 단방향.**
- 바닥에서 퍼지고, 벽에서 처지고, 공중에서 늘어나는 비주얼 연출.
- **게임플레이 수치(발사력, 방향, 상태 전환)에는 일절 관여하지 않음.**
- Phase 1의 게임플레이 코드를 건드리지 않고 추가 가능.

이하 문서는 **Phase 1 (단일 원형 콜라이더)** 기준으로 작성.

## 2. 표면 부착 & 드리프트

### 부착 판정

- 원형 콜라이더가 표면에 접촉하면 **Attached 상태** 진입.
- 부착 판정은 `Physics2D.OverlapCircle` 또는 충돌 콜백으로 처리.

### 벽/천장 드리프트

Attached 상태에서 표면이 수직/천장에 가까울수록 중력 방향으로 흘러내린다.

```
surfaceUp = dot(surfaceNormal, Vector2.up);        // 바닥=1, 벽=0, 천장=-1
driftMultiplier = 1 - clamp01(surfaceUp);            // 바닥=0, 벽=1, 천장=1
centerDrift = baseDriftSpeed * driftMultiplier * dt;
centerNode.Position += gravity.normalized * centerDrift;
```

- **바닥**: 드리프트 없음. 여유롭게 조준 가능.
- **벽**: 중력 방향으로 흘러내림. 빨리 쏘면 높은 위치에서 발사, 늦으면 낮아짐.
- **천장**: 벽과 동일하게 흘러내림. 부착 유지 시간이 짧음.
- **경사면**: 기울기에 비례하여 연속적으로 드리프트. 급할수록 빨리 미끄러짐.

드리프트로 표면 끝에 도달하면 Attached 해제 → Airborne 전환.

### 불안정한 표면의 페널티

**발사력 공식에 안정도/페널티 계수는 없다.** 파워는 순수하게 차징 시간으로만 결정.

불안정한 표면(벽, 천장, 좁은 플랫폼)에서의 난이도는 **물리적 시간 제한**으로 발생:
- 벽/천장에서 흘러내리므로 차징 시간이 제한됨 → 짧은 차징 = 약한 파워.
- 풀차지 자동 발사가 다가오면서 이중 압박.
- 좁은 플랫폼에서는 크롤링 여유가 없어 위치 잡기가 어려움.
- 경사면에서는 차징 중에도 미끄러짐.

별도의 안정도 시스템이나 노드 기반 계수 없이, 물리 상황 자체가 난이도를 만든다.

## 3. 표면별 상호작용

### 바닥

- 드리프트 없음. 안정적.
- 차징 시간 제한 없음 (풀차지 자동 발사만 존재).
- 여유롭게 조준 가능.

### 벽

- 중력 방향으로 드리프트.
- 빨리 쏘면 높은 위치에서 발사. 늦으면 낮아짐.
- 자연스러운 시간 압박.

### 천장

- 벽과 동일하게 드리프트. 부착 유지 시간이 더 짧음.
- 천장 발사는 고급 테크닉.

### 좁은 플랫폼

- 크롤링으로 위치 미세 조정이 중요.
- 가장자리에서 떨어지기 쉬움.

### 경사면

- 기울기에 비례하여 드리프트.
- 차징 중에도 미끄러짐 — 경사 위에서 정밀 조준이 어려움.

---

## 4. 이동

### 표면 크롤링

- 스페이스를 누르지 않은 상태에서 **WASD**로 천천히 기어다님.
- 바닥: A/D 좌우. 벽: W/S 위아래. 천장: A/D 좌우.
- 이동 속도는 느림 — 위치 미세 조정용이지 주 이동 수단이 아님.
- **스페이스 홀드 중에는 A/D가 조준 회전으로 전환.** 크롤링 중단. W/S는 차징 중 미사용.

### 주 이동 수단: 차징 발사

- 표면에서 표면으로의 이동은 전부 차징 발사로 수행.

## 5. 차징 & 발사

### 원리

슬라임이 내부적으로 압축된 뒤, 압축 반대 방향으로 튕겨나가는 슬링샷 방식.  
**차징은 슬라임 자체의 내부 메커니즘**이며, 접촉 표면과는 독립적으로 동작한다.  
**모든 표면에서 차징 가능** — 바닥, 벽, 천장 어디서든.

### 압축-발사 모델

차징 시 슬라임이 특정 방향으로 몸을 압축하고, 발사 시 **압축 반대 방향**으로 날아간다.

- A 입력으로 압축 방향이 왼쪽으로 기울어짐 → 발사는 오른쪽으로.
- D 입력으로 압축 방향이 오른쪽으로 기울어짐 → 발사는 왼쪽으로.
- 비주얼: 차징 중 슬라임이 압축 방향으로 찌그러지고, 발사 시 반대로 늘어나면서 튀어나감.

### 초기 방향 & 조준

- **스페이스 홀드 = 차징 시작.** 초기 압축 방향은 **접촉 표면의 법선 안쪽** (표면을 향해 눌림). 발사 기본 방향은 법선 바깥쪽.
  - 바닥: 기본 압축 아래, 기본 발사 위.
  - 오른쪽 벽: 기본 압축 오른쪽, 기본 발사 왼쪽.
  - 30° 경사면: 기본 발사 경사 수직 방향.
- **A/D = 조준 회전.** 차징 중 A/D로 압축 방향을 초기 법선 기준으로 회전. 아날로그 각도 조절.
- **W/S는 차징 중 미사용.**

```
// 차징 진입 시
initialAngle = surfaceNormal.angle;  // 법선 방향 (발사 기본 방향)
currentAngle = 0;                     // 법선 기준 오프셋

// 매 프레임
currentAngle += input.x * rotationSpeed * dt;  // A/D 회전

// 압축 방향 = 발사 반대
launchDirection  = angleToVector(initialAngle + currentAngle);
compressDirection = -launchDirection;
```

표면 종류에 따라 입력을 다르게 매핑할 필요 없음. "법선에서 시작, A/D로 돌림"이라는 하나의 규칙이 바닥/벽/천장/경사면에 자동으로 맞아떨어짐.

### 차징 파워와 조준 관성

차징량이 높을수록 조준 회전이 뻑뻑해진다. 에너지가 많이 실린 상태에서는 관성이 커서 방향 전환이 어려움.

```
rotationSpeed = baseRotationSpeed * max(minFraction, 1 - chargeRatio * resistFactor);
```

- **약하게 차징**: 회전 자유. 조준 정밀.
- **강하게 차징**: 회전 경직. 방향을 미리 잡아놔야 함.

### 큐빅 커브와 자연스러운 조준-파워 페이즈 분리

파워 커브가 **큐빅(t³)**이므로, 초반에는 chargeRatio가 거의 올라가지 않는다. 이 구간이 자연스러운 조준 페이즈가 된다.

풀차지 시간 **1초** 기준 (튜닝 출발점):

| 구간 | chargeRatio | 조준 상태 | 역할 |
|------|-------------|-----------|------|
| 0.0 ~ 0.4초 | 0 ~ 0.064 | 회전 거의 자유 | **조준 페이즈** — 방향 잡기 |
| 0.4 ~ 0.7초 | 0.064 ~ 0.34 | 슬슬 뻑뻑해짐 | **미세 보정** — 방향 확정 |
| 0.7 ~ 1.0초 | 0.34 ~ 1.0 | 급격히 잠김 | **파워 페이즈** — 파워만 충전 |

별도의 조준 타이머 없이, 큐빅 커브 하나가 조준 여유 / 파워 곡선 / 회전 경직을 동시에 제어.

### 발사 트리거 (2가지)

1. **스페이스 릴리즈** — 원하는 타이밍에 수동 발사.
2. **풀차지 자동 발사** — 차지 게이지가 최대에 도달하면 즉시 자동 발사.

풀차지 자동 발사 시간 압박:
- 벽/천장에서 흘러내리면서 차징 시간도 줄어듦.
- 차지 게이지가 차오르면서 의도치 않은 타이밍에 발사될 수 있음.

### 발사력 공식

```
launchPower = baseLaunchPower * chargeCurve(t)
```

**이것이 전부.** 안정도, 노드 수, 표면 종류, 각도 — 아무것도 개입하지 않음.  
플레이어가 보는 건 "얼마나 눌렀느냐 = 얼마나 세게 나가느냐" 하나뿐.  
불안정한 표면의 페널티는 물리적 시간 제한(드리프트)으로 자연스럽게 발생.

### 차징 규칙

- 홀드 시간에 비례하여 파워 증가. **큐빅 커브 (t³).**
- **풀차지 시간: 1초** (튜닝 출발점).
- **차징 캔슬 불가.** 스페이스를 누르면 무조건 발사까지 진행. 커밋.
- **발사 후 입력 무시 윈도우: 0.05초.** 잔여 키 입력 무효화.

## 6. 벽 충돌 — 바운스 없음, 에너지 전환

### 핵심 원칙

**벽에 부딪히면 튕겨나오지 않는다.** 무조건 벽에 붙는다.  
바운스 메커니즘은 전면 삭제.

### 두 가지 충돌 모드

| 충돌 시 스페이스 상태 | 결과 |
|----------------------|------|
| **안 누르고 있었음** | 철퍼덕 붙음. 운동에너지 전부 소멸. 이후 일반 차징으로 발사. |
| **누르고 있었음** | 충돌 속력이 차징 에너지로 전환. 이미 차지가 차있는 상태로 벽에 붙음. |

### 운동에너지 전환 규칙

```
normalSpeed = max(0, dot(velocity, -wallNormal));  // 법선 방향 성분만 사용
storedRatio = min(normalSpeed * conversionRate / baseLaunchPower, 1.0);
```

- 전환된 에너지는 차지 게이지의 **초기값**으로 세팅. 일반 차징의 풀파워가 상한.
- 빠르게 박으면 거의 풀차지 상태 → 조준 회전이 뻑뻑하고 풀차지 자동 발사까지 여유 없음.
- 느리게 닿으면 반차지 정도 → 조준 자유롭고 여유 있지만 파워 약함.
- **비스듬히 닿으면 법선 성분만 전환.** 스치듯 지나가는 것은 전환량이 적음.
- 벽에 붙은 후 스페이스를 계속 들고 있으면 게이지가 계속 차오름. 놓으면 수동 발사, 풀차지되면 자동 발사.
- **차징 시간 역산**: 전환된 chargeRatio에 해당하는 t에서 차징 시작. `t_start = cbrt(storedRatio) * maxDuration`.

### 방향 입력

- 운동에너지 전환 시에도 **벽에 붙은 순간부터** A/D로 조준 회전 가능.
- 단, 전환된 차지량이 높을수록 회전이 뻑뻑함 — 빠르게 박으면 방향 전환 여유가 적음.

### 난이도의 종류 분화

같은 벽 구간을 두 가지 방식으로 공략 가능:
- **안전 루트**: Space 안 누르고 붙음 → 에너지 소멸 → 일반 차징. 쉬운 조준, 약한 파워. 여러 번 쏴야 함.
- **스피드 루트**: Space 누르고 빠르게 박음 → 높은 전환량 → 강한 파워. 뻑뻑한 조준, 한 방에 넘김.

### 설계 의도

**사전 커밋 원칙의 일관성**: 차징도 캔슬 불가, 벽 충돌도 "부딪히기 전에 스페이스를 누를지 말지 미리 결정해야 한다." 예측하고 커밋한 플레이어가 보상받는 구조.

## 7. 공중 제어

- **A/D**: 속도 벡터의 **방향만 회전.** 총 속력과 수직 속도는 보존.
- 완전한 U턴 불가능, 완만한 곡선 보정만 가능.

```
float originalSpeed = velocity.magnitude;
float currentAngle = atan2(velocity.y, velocity.x);
float maxDelta = airControlAngularSpeed * dt / originalSpeed;
currentAngle += input.x * maxDelta;
velocity = angleToVector(currentAngle) * originalSpeed;
```

### 대칭 중력

- **상승/하강 동일한 중력 적용.** 비대칭 중력(fallMultiplier) 삭제.
- 대칭 포물선으로 궤적 예측 가능성 극대화.
- 체공감이 과하면 기본 gravity scale을 올려서 조절 (포물선이 납작해지면서 상승도 하강도 빨라짐).
- 차징-커밋 구조에서는 "이만큼 차징하면 이 포물선"을 학습하는 게 핵심. 대칭이 학습에 유리.

## 8. 프로토타입 초기 수치 (튜닝 출발점)

| 항목 | 수치 |
|------|------|
| **콜라이더** | |
| 충돌 형태 | 단일 원형 콜라이더 |
| **중력** | |
| 중력 | 대칭. gravity scale로 조절 (fallMultiplier 없음) |
| **벽/천장 드리프트** | |
| 기본 드리프트 속도 (baseDriftSpeed) | 튜닝 필요 |
| 드리프트 = baseDriftSpeed × (1 - surfaceUp) | surfaceUp = dot(normal, up) |
| **공중 제어** | |
| 에어 컨트롤 | 속도 벡터 방향 회전 (속력 보존) |
| 에어 컨트롤 각속도 (airControlAngularSpeed) | 튜닝 필요 |
| **차징** | |
| 차징-파워 커브 | 큐빅 (t³) |
| 풀차지 시간 | 1초 (튜닝 출발점) |
| 발사력 공식 | baseLaunchPower × chargeCurve(t). 다른 계수 없음 |
| 기본 발사력 (baseLaunchPower) | 튜닝 필요 |
| 발사 방향 | 표면 법선 기준 A/D 아날로그 회전 |
| 기본 조준 회전 속도 (baseRotationSpeed) | 튜닝 필요 |
| 조준 관성 계수 (resistFactor) | 튜닝 필요 |

## 9. 입력 요약

### 표면 (바닥/벽/천장 공통)

| 입력 | 동작 |
|------|------|
| WASD | 표면 위 크롤링 |
| Space 홀드 | 차징 시작 (초기 방향 = 표면 법선) |
| Space + A/D | 조준 회전 (차징량 많을수록 뻑뻑해짐) |
| Space 릴리즈 | 발사 (수동) |
| Space 홀드 → 풀차지 | 발사 (자동) |

### 공중

| 입력 | 동작 |
|------|------|
| A / D | 궤도 방향 회전 (속력 보존) |
| Space 홀드 | 벽 충돌 시 운동에너지 전환 준비 |

### 벽 충돌

| 충돌 시 상태 | 결과 |
|-------------|------|
| Space 안 누름 | 붙음. 에너지 소멸. 일반 차징 시작 가능. |

## 10. 설계 원칙 요약

1. **원 하나가 게임 전부**: 단일 원형 콜라이더로 모든 게임플레이 동작. 소프트바디는 비주얼 오버레이로 나중에 추가.
2. **점성 슬라임**: 모든 표면에 달라붙는다. 바운스 없음.
3. **파워는 차징 시간 하나로만**: 안정도, 노드 수, 표면 각도 등 어떤 계수도 발사력에 개입하지 않음.
4. **불안정함은 시간이 만든다**: 벽/천장/경사면에서 드리프트로 시간 제한. 별도 페널티 시스템 불필요.
5. **입력 단순**: WASD + Space. 5개 키로 모든 조작.
6. **차징은 커밋**: 캔슬 불가. 방향은 A/D 회전으로 발사 순간까지 조절 가능.
7. **파워-조준 트레이드오프**: 강하게 쏘면 조준이 뻑뻑해지고, 약하게 쏘면 조준이 자유롭다. 큐빅 커브가 자연스러운 조준→파워 페이즈 전환을 만든다.
8. **사전 커밋 보상**: 벽 충돌 전 스페이스를 미리 누른 플레이어가 에너지 전환 보상을 받음. 높은 전환량 = 조준 여유 감소.
9. **대칭 중력**: 포물선 예측 가능성. 차징-커밋 구조에 최적.
10. **시스템 분리**: 중력 → 수직, 에어 컨트롤 → 방향 회전(속력 보존). 차징 시스템은 표면을 모르는 채로 독립 동작. 드리프트는 표면 법선만으로 결정.

# Screen Space - Overlay 캔버스가 Game 뷰 맨 윗줄을 못 덮음

**발견:** 2026-08-18 (VoidRespawn 페이드 작업 중) · **상태:** 원인 후보 확정(측정 완료), 코드 수정 없음, 빌드 검증 미수행
**관련 코드:** [VoidRespawn.cs](../../SlimeJumping_v2/Assets/Scripts/Controller/VoidRespawn.cs)

---

## 1. 증상

맵 밖 낙하 페이드(검은 전체화면 판)를 깔면 화면이 다 검어지지 않고 **위쪽에 밝은 가로 띠가 남는다**. 페이드아웃·페이드인 양쪽 모두. Game 뷰에서만 확인됨(빌드 미확인).

## 2. 측정값

일시정지된 Play 세션에서 직접 읽음:

```
Display.main.rendering    1343 x 821      실제 렌더 타겟 (정수)
Main Camera pixelRect     1343 x 820.5    카메라/UI 뷰포트 (소수)
Main Camera pixelHeight   821             위 값 반올림
Screen.dpi                144             = 윈도우 배율 150%
VoidRespawnFade canvasRect 1343 x 820.5   scaleFactor 1
검은 Image 월드 코너       BL(0,0) TR(1343, 820.5)
```

즉 **캔버스 공간에서는 이미지가 카메라 렉트를 100% 덮고 있다.** 그런데도 띠가 남는다.

`ScreenCapture.CaptureScreenshot` 으로 받은 실제 프레임(당시 창 크기 1343x819)에서 빨간 전체화면 판을 깔고 안 칠해진 픽셀을 세면:

```
buffer 1343 x 819
판 rect 1280 x 960          ← 세로가 버퍼보다 141px 더 큼
안 칠해진 영역  top 1 · bottom 0 · left 31 · right 32
```

좌우 31/32 는 판이 가로로 좁아서(1343−1280)/2 로 설명된다. **세로는 141px 이나 더 크게 덮었는데도 맨 윗줄 1행이 그대로 비었다.**

같은 프레임 맨 윗줄 픽셀값: `(66,66,74) (65,64,70) (40,32,28) (40,34,32) (37,29,23)` — 게임 화면 픽셀이 들어 있다. **카메라 렌더는 그 줄을 칠하고, UI 오버레이 패스만 안 칠한다.**

## 3. 원인 (측정으로 지목, 최종 확증은 빌드 테스트)

1. Game 뷰 패널 높이가 논리 픽셀로 **820.5** 로 떨어진다(창 높이 ÷ DPI 배율 150% 가 정수가 아님).
2. 렌더 타겟은 정수여야 하므로 **821행**.
3. UI 오버레이 패스는 카메라 뷰포트(높이 **820.5**)로 스케일/시저를 건다.
4. 타겟 맨 윗줄은 인덱스 820, 픽셀 중심 y = 820.5 — 시저 경계와 정확히 일치. 경계에 걸친 픽셀은 커버리지 판정에서 탈락 → 그 한 줄이 영원히 안 칠해진다.

RectTransform 을 아무리 키워도 안 되는 이유가 4번이다. 잘리는 주체가 메시가 아니라 **뷰포트/시저**다.

카메라 렌더가 그 줄을 채우는 이유: MSAA 8 · HDR 이라 중간 RT(1343×821)에 그린 뒤 타겟 전체로 blit 하므로 뷰포트 소수점과 무관하다.

## 4. 반례로 폐기된 원인

| 가설 | 반례 |
|---|---|
| 이미지가 캔버스 rect 를 못 채움 (anchor/offset 문제) | 월드 코너가 캔버스 rect 와 정확히 일치. 유저가 인스펙터에서 더 키워도 동일 |
| 오버스캔(이미지를 화면 밖까지 확장)으로 해결 | 세로 141px 초과분을 덮어도 top 1행 그대로 — 유저 실측도 "똑같다" |
| `sortingOrder 30000` 이 비정상이라 다른 캔버스가 위에 그려짐 | 유효 범위(short, ±32767) 안. 씬 캔버스 실측 = HudLayer 100 / MenuLayer 500 / ModalLayer 800 / FullscreenLayer 9000, 전부 sorting layer `Default` |
| Game 뷰 Gizmos 가 캔버스 rect 외곽선을 덧그림 ([포럼 사례](https://discussions.unity.com/t/why-is-there-a-canvas-line-on-top-of-my-game-screen/203817)) | 유저가 Gizmos 끄고 재현 — 증상 동일 |

## 5. 대응

- **빌드에서는 안 나올 것으로 본다**: 플레이어 창은 클라이언트 영역이 정수 픽셀이고 `Screen.width/height` 도 정수라 `rect(0..1) × 정수 = 정수`, 3~4번 조건이 성립하지 않는다. **창모드 빌드 확인은 아직 안 했다.**
- 에디터에서 안 보이게: Game 뷰 Aspect 를 Free Aspect → 고정 해상도(1920x1080 등)로. 높이가 정수면 사라진다.
- 에디터에서도 구조적으로 막고 싶으면: 페이드 캔버스를 `Screen Space - Camera`(현재 스택 비어 있으므로 Main Camera)로 내린다. 카메라 층은 blit 로 채워지므로 그 줄까지 덮인다. 대가 = 카메라 참조 필요, 나중에 Overlay 카메라를 스택에 추가하면 그 내용이 페이드 위로 올라온다. **현재 코드는 Overlay 유지 상태.**

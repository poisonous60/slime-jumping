# SlimeJumping — 핵심 메커닉 설계 문서

## 컨셉

**점성 슬라임** — 모든 표면에 달라붙는 것이 자연 상태. 이동은 차징 발사로만.  
슬라임의 물성 자체가 게임 메커닉: 중력으로 처지고, 부착 면적이 줄면 불안정해지고, 불안정할수록 발사가 약해진다.  
WASD + Space 키로 조작. 모든 시간 단위는 **초(seconds)** 기준.

---

## 1. 슬라임 물리 시스템 (멀티 노드)

### 구조

중심 1개 + 주변 6개, 총 **7개 노드**가 스프링으로 연결된 링 구조.

```
      ●
     / \
   ●  ●  ●    중심(C) + 주변 6개(N)
   |  C  |     C↔N 스프링 + N↔N 스프링
   ●  ●  ●
     \ /
      ●
```

- **C↔N 스프링**: 중심과 주변 노드 연결. 슬라임의 전체 형태 유지.
- **N↔N 스프링**: 이웃 주변 노드끼리 연결. 외곽 형태 유지.
- 스프링 파라미터 (강성, 감쇠)로 슬라임의 탱탱함/물렁함 조절.

### 기본 물리

- 모든 노드에 **중력** 적용.
- 스프링 복원력으로 형태 유지하려 함.
- 중력 vs 스프링의 균형이 슬라임의 "처짐"을 결정.

### 표면 부착

- 노드가 표면에 닿으면 **달라붙음** (부착 상태).
- 부착된 노드는 표면 위치에 고정. 스프링 장력이 **부착력**을 초과하면 떨어짐.
- 부착력은 튜닝 가능한 상수.

### 안정도

```
안정도 = 부착된 노드 수 / 전체 노드 수
```

안정도가 높을수록 (많이 붙어있을수록) 발사력이 강하고 방향이 정확. 안정도가 낮으면 발사가 약하고 방향이 틀어짐.

### 무게중심 오프셋

부착점(부착 노드들의 평균 위치)과 무게중심(전체 노드의 평균 위치) 사이의 거리.  
이 오프셋이 발사 방향에 편향을 준다 — 무게중심이 처진 쪽으로 발사 방향이 살짝 틀어짐.

---

## 2. 표면 상호작용

### 바닥

- 착지하면 슬라임이 바닥에 퍼지면서 다수의 노드가 부착. 안정도 높음.
- 시간이 지나도 안정적. 여유롭게 조준 가능.

### 벽

- 벽에 닿으면 벽쪽 노드가 부착.
- 부착되지 않은 노드가 중력으로 서서히 아래로 처짐.
- 시간이 지날수록 무게중심이 아래로 이동 → 안정도 하락 → 스프링 장력이 부착력 초과 시 노드 떨어짐 → 추가 안정도 하락 → 결국 벽에서 떨어짐.
- **빨리 쏘면 높은 위치에서 강하게 발사. 늦으면 낮아지고 약해짐.** 자연스러운 시간 압박.

### 천장

- 천장쪽 노드가 부착, 나머지 전부 아래로 처짐.
- 벽보다 더 불안정. 처지는 속도가 빠르고 부착 유지 시간이 짧음.
- 천장에서 발사하는 건 고급 테크닉 — 짧은 시간 안에 차징해서 쏴야 함.

### 좁은 플랫폼

- 부착 가능한 표면이 작아서 소수의 노드만 부착.
- 나머지 노드가 양옆 또는 아래로 처짐.
- 안정도가 기본적으로 낮음 → 정밀한 위치 조정이 중요.

### 원형/곡면 플랫폼

- 곡면을 따라 여러 노드가 부착.
- 무게중심이 부착점 바로 아래에 있으면 균형 유지. A/D로 이동하면 무게중심이 쏠리면서 기울어짐.
- 너무 쏠리면 떨어짐.

---

## 3. 이동

### 표면 크롤링

- 스페이스바를 누르지 않은 상태에서 **WASD**로 천천히 기어다님.
- 바닥이면 A/D 좌우, 벽이면 W/S 위아래, 천장이면 A/D 좌우.
- 이동 속도는 느림 — 위치 미세 조정용이지 주 이동 수단이 아님.
- 이동 시 노드가 순차적으로 부착/해제되면서 슬라임이 "흘러가는" 비주얼.
- **스페이스바 홀드 중에는 WASD가 발사 방향 조준으로 전환.** 크롤링 중단.

### 주 이동 수단: 차징 발사

- 표면에서 표면으로의 이동은 전부 차징 발사로 수행.

## 4. 차징 & 발사

### 원리

슬라임이 표면을 눌러서 찌그러진 뒤, 표면 반대 방향으로 튕겨나가는 슬링샷 방식.  
**모든 표면에서 차징 가능** — 바닥, 벽, 천장 어디서든.

### 차징 입력

**스페이스바 홀드 = 차징.** 어떤 표면이든 동일.  
**WASD = 발사 방향 조준.** 스페이스바를 누르고 있는 동안 WASD로 방향 지정.

| 입력 | 발사 방향 |
|------|-----------|
| Space만 | 표면 법선 방향 (표면에서 수직으로 떨어짐) |
| Space + W | 위 |
| Space + S | 아래 |
| Space + A | 왼쪽 |
| Space + D | 오른쪽 |
| Space + WA | 왼쪽 위 대각선 |
| Space + WD | 오른쪽 위 대각선 |
| Space + SA | 왼쪽 아래 대각선 |
| Space + SD | 오른쪽 아래 대각선 |

방향은 **절대 방향** (표면 상관없이). 바닥이든 벽이든 천장이든 W는 항상 위, D는 항상 오른쪽.  
스페이스바가 차징 전용이라 WASD와 입력 충돌 없음.

### 차징 규칙

- 홀드 시간에 비례하여 발사 파워 증가. **후반 급상승 커브 (큐빅 이상)** 권장.
- **방향은 차징 시작 시 확정.** 스페이스바를 누르는 순간 WASD 상태로 방향 결정. 차징 중 방향 변경 불가.
- **방향 입력 버퍼: 0.1초.** 스페이스가 먼저 눌려도 0.1초 이내에 WASD가 입력되면 해당 방향으로 판정.
- **차징 캔슬 불가.** 스페이스를 누르면 무조건 발사까지 진행. 커밋.
- **발사 트리거: 스페이스바 릴리즈.** 단순 명확.
- **발사 후 입력 무시 윈도우: 0.05초.** 잔여 키 입력 무효화.

### 각도 조절

WASD 조합으로 **9방향** (8방향 + 중립) 발사 가능.  
Q/E 불필요 — WASD만으로 모든 각도를 커버.  
각도 수치는 레벨 디자인에 맞춰 튜닝. 대각선 각도가 정확히 45°일 필요 없음.

### 안정도가 발사에 미치는 영향

```
실제 발사력 = 기본 발사력 × 안정도
발사 방향 = 의도 방향 + 무게중심 오프셋 × 편향 계수
```

- **안정도 높음** (바닥, 넓은 표면): 풀파워, 정확한 방향.
- **안정도 낮음** (벽에서 처진 상태, 좁은 플랫폼): 약한 파워, 방향 틀어짐.
- 착지 직후 빠르게 발사 → 강하고 정확. 시간 끌면 → 약하고 부정확.
- 슬링샷 비주얼: 발사 방향 반대쪽으로 슬라임이 늘어나는 연출.

---

## 5. 공중 제어

- **A/D**: 수평 방향만 약하게 보정. 수직 속도는 절대 건드리지 않음.
- 에어 컨트롤은 **방향만 틀고 속력은 바꾸지 않음.** 같은 방향 가속도 불가.
- 완전한 U턴은 불가능, 완만한 곡선 보정 정도만 가능.

### 비대칭 중력

- **상승 중**: 기본 중력 적용.
- **하강 중**: 중력 2.5배 (`fallMultiplier`). 빠른 하강.
- 에어 컨트롤과 중력이 축 분리 (수평/수직)되어 서로 간섭하지 않음.

### 공중 슬라임 형태

- 공중에서 노드들이 자유롭게 움직이며 슬라임이 늘어지거나 회전.
- 표면에 닿는 순간 접촉 노드가 부착되면서 착지 형태 결정.
- 어떤 각도로 착지하느냐에 따라 부착 노드 수와 위치가 달라짐 → 착지 자세가 다음 발사에 영향.

## 8. 설계 원칙 요약

1. **점성 슬라임**: 모든 표면에 달라붙는다. 멈춰있는 게 자연 상태.
2. **물성이 곧 메커닉**: 처짐, 안정도, 무게중심이 발사에 직접 영향. 단순한 비주얼이 아님.
3. **입력 단순**: WASD + Space. 5개 키로 모든 조작. 크롤링과 조준이 WASD로 통일, 스페이스가 모드 전환.
4. **시간 압박은 물리에서 나온다**: 벽/천장에서 슬라임이 처지면서 안정도가 하락. 별도 타이머 불필요.
5. **착지 자세가 다음 발사에 영향**: 어떻게 착지하느냐가 다음 행동의 품질을 결정.
6. **차징은 커밋**: 캔슬 불가. 신중한 결정을 요구.
7. **시스템 분리**: 중력 → 수직, 에어 컨트롤 → 수평. 서로 간섭하지 않음.

## 9. 삭제된 시스템 (이전 버전 대비)

탄성 슬라임에서 점성 슬라임으로 전환하며 삭제:

- 자동 바운스 (전체)
- W 펌핑 (바운스 부스트)
- 벽 바운스 방향 편향
- 벽 라이딩
- 표면별 바운스 보존율
- 홉 이동
- 비대칭 중력 바운스 보정
- Q/E 각도 조절 키
- 표면별 차징 키 (S/A/D/W) → 스페이스바로 통일
